## 1. 行列式是带符号的面积与体积

二阶行列式定义为

$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc.$$

它的绝对值等于向量 $(a,c)$ 与 $(b,d)$ 张成的平行四边形的面积，符号表示这两个向量的相对方向：从第一个向量转到第二个向量是逆时针则为正，顺时针则为负。

三阶行列式的绝对值等于三个列向量张成的平行六面体的体积，符号同样表示定向。若三个向量共面，体积为 0，行列式也为 0。

这个几何解释说明：行列式衡量线性变换“把体积放大或缩小了多少倍”。若 $\det\mathbf{A}=0$，变换把空间压到更低维，体积变为 0，信息不可逆。

## 2. 2×2 与 3×3 的计算

二阶：

$$\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc.$$

三阶可以用对角线法则：

$$\begin{vmatrix}
a&b&c\\
d&e&f\\
g&h&i
\end{vmatrix}
=aei+bfg+cdh-ceg-bdi-afh.$$

三条主对角线方向的乘积取正号，三条副对角线方向的乘积取负号。

**例 6.1**　计算

$$\mathbf{A}=\begin{pmatrix}
2&1&0\\
1&3&1\\
0&1&2
\end{pmatrix}$$

的行列式。

按第一行展开：

$$
\begin{aligned}
\det\mathbf{A}
&=2\begin{vmatrix}3&1\\1&2\end{vmatrix}
-1\begin{vmatrix}1&1\\0&2\end{vmatrix}
+0\begin{vmatrix}1&3\\0&1\end{vmatrix}\\
&=2(6-1)-(2-0)=10-2=8.
\end{aligned}
$$

> **注意**：对角线法则只适用于 2×2 和 3×3，不能推广到 4×4 及以上。高阶行列式要用余子式展开或行变换。

## 3. 行列式的性质

行列式是“多线性”和“反对称”的函数。常用性质如下：

1. $\det(\mathbf{A}\mathbf{B})=\det(\mathbf{A})\det(\mathbf{B})$。
2. $\det(\mathbf{A}^\top)=\det(\mathbf{A})$。
3. 交换两行（或两列），行列式变号。
4. 某一行乘以 $c$，行列式乘以 $c$；因此 $\det(c\mathbf{A})=c^n\det(\mathbf{A})$（$n$ 阶）。
5. 把一行的倍数加到另一行，行列式不变。
6. 若有两行相同或成比例，行列式为 0。
7. 三角矩阵的行列式等于对角线元素之积。
8. 若 $\mathbf{A}$ 可逆，则 $\det(\mathbf{A}^{-1})=\dfrac{1}{\det(\mathbf{A})}$。

这些性质让计算可以大幅简化：先用行变换把矩阵化成三角形，再把对角线乘起来。

**例 6.2**　计算

$$\begin{vmatrix}
1&2&3\\
2&4&6\\
7&8&9
\end{vmatrix}.$$

第二行是第一行的 2 倍，两行成比例，所以行列式为 0。

**例 6.3**　计算

$$\begin{vmatrix}
1&2&3\\
0&4&5\\
0&0&6
\end{vmatrix}=1\cdot 4\cdot 6=24.$$

## 4. 代数余子式展开

划去第 $i$ 行第 $j$ 列后剩下的行列式，叫元素 $a_{ij}$ 的**余子式** $M_{ij}$。加上符号

$$C_{ij}=(-1)^{i+j}M_{ij}$$

叫**代数余子式**。行列式可以沿任意一行或一列展开：

$$\det\mathbf{A}=\sum_{j=1}^n a_{ij}C_{ij}
=\sum_{i=1}^n a_{ij}C_{ij}.$$

选择含零最多的行或列展开，计算量最小。

**例 6.4**　沿第一列展开例 6.1 的矩阵：

$$
\det\mathbf{A}
=2\begin{vmatrix}3&1\\1&2\end{vmatrix}
-1\begin{vmatrix}1&0\\1&2\end{vmatrix}
+0
=2\cdot 5-1\cdot 2=8.
$$

结果与按第一行展开一致。

## 5. 可逆性、Cramer 法则与雅可比

方阵 $\mathbf{A}$ 可逆，当且仅当

$$\det(\mathbf{A})\ne 0.$$

若 $\det(\mathbf{A})=0$，称 $\mathbf{A}$ 奇异。奇异矩阵的列线性相关，零空间非平凡，映射不可逆。

**Cramer 法则**：若 $\mathbf{A}$ 可逆，方程组 $\mathbf{A}\mathbf{x}=\mathbf{b}$ 的解为

$$x_i=\frac{\det(\mathbf{A}_i)}{\det(\mathbf{A})},$$

其中 $\mathbf{A}_i$ 是把 $\mathbf{A}$ 的第 $i$ 列换成 $\mathbf{b}$ 得到的矩阵。

Cramer 法则形式漂亮，但计算量大：每求一个分量都要算一个行列式，实际工程中很少用它，更多用 LU 分解或迭代法。它的价值在于理论分析。

**雅可比行列式**：多元换元积分时，体积元要乘以变换的雅可比行列式的绝对值：

$$\mathrm{d}x\,\mathrm{d}y=|\det\mathbf{J}|\,\mathrm{d}u\,\mathrm{d}v.$$

例如极坐标 $x=r\cos\theta$，$y=r\sin\theta$，雅可比矩阵为

$$\mathbf{J}=\begin{pmatrix}
\cos\theta&-r\sin\theta\\
\sin\theta&r\cos\theta
\end{pmatrix},\qquad
\det\mathbf{J}=r.$$

所以 $\mathrm{d}x\,\mathrm{d}y=r\,\mathrm{d}r\,\mathrm{d}\theta$。这正是二重积分极坐标公式的来源。

## 6. 工程视角：换元与不确定性

行列式在工程中至少有三类用途：

- **换元与积分**：概率密度、体积元、坐标变换都要乘雅可比行列式；
- **可逆性判断**：控制系统、标定矩阵、协方差矩阵是否退化，看行列式是否接近 0；
- **不确定性体积**：多元高斯分布的协方差矩阵行列式决定置信椭球的体积，$\det\boldsymbol{\Sigma}$ 越小，估计越集中。

数值上要注意：行列式接近 0 并不一定说明矩阵“几乎不可逆”到无法使用，条件数才是更可靠的指标（第 10 课）。一个行列式很小的矩阵可能只是尺度小，方向仍然很清楚。

> **小实验**：用 NumPy 计算行列式，并观察行变换对它的影响。

```python
import numpy as np

A = np.array([[2, 1, 0], [1, 3, 1], [0, 1, 2]])
print(np.linalg.det(A))  # 约 8

B = A.copy()
B[1] = B[0]              # 让两行相同
print(np.linalg.det(B))  # 0
```

## 8. 答案与简解

**1.** $3\cdot 4-1\cdot 2=10$。

**2.** 已算得 $\det\mathbf{A}=8\ne 0$，所以可逆。

**3.** $1\cdot 4-2\cdot 2=0$。第二列是第一列的 2 倍，两列线性相关，矩阵奇异，不可逆。

**5.** 面积为行列式的绝对值：

$$\left|\begin{vmatrix}3&1\\1&2\end{vmatrix}\right|=|6-1|=5.$$
