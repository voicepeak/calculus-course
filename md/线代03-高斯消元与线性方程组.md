## 1. 线性方程组与增广矩阵

一个线性方程组写成

$$
\begin{cases}
a_{11}x_1+\cdots+a_{1n}x_n=b_1,\\
\quad\vdots\\
a_{m1}x_1+\cdots+a_{mn}x_n=b_m.
\end{cases}
$$

把系数和常数项排在一起，得到**增广矩阵**：

$$\left[\mathbf{A}\mid\mathbf{b}\right]=
\left(
\begin{array}{ccc|c}
a_{11}&\cdots&a_{1n}&b_1\\
\vdots&\ddots&\vdots&\vdots\\
a_{m1}&\cdots&a_{mn}&b_m
\end{array}
\right).$$

解方程组时，我们只关心系数之间的关系，变量名 $x_1,\dots,x_n$ 只是占位符。因此可以对增广矩阵做行变换，而不必反复抄写变量。

---

## 2. 初等行变换

下面三种操作不改变方程组的解集：

1. 交换两行；
2. 把某一行乘以一个非零常数；
3. 把某一行的倍数加到另一行上。

这三种操作叫**初等行变换**。它们对应方程组的合法变形：交换方程顺序、两边同乘非零数、两个方程相减。

注意：**不能交换列**，因为列对应变量，交换列会改变变量的含义；**不能把某行乘以 0**，那会丢失方程。

高斯消元的目标，是用行变换把矩阵化成容易回代的形式。

---

## 3. 行阶梯形与简化行阶梯形

**行阶梯形**（row echelon form）满足：

- 非零行在零行上方；
- 每一行的第一个非零元（主元）在上一行主元的右边；
- 主元所在列的下方全为 0。

**简化行阶梯形**（RREF）还要求：

- 每个主元都是 1；
- 主元所在列的其他元素全为 0。

**例 3.1**　解方程组

$$
\begin{cases}
x+y+z=6,\\
2x-y+z=3,\\
x+2y-z=2.
\end{cases}
$$

增广矩阵：

$$\left(
\begin{array}{ccc|c}
1&1&1&6\\
2&-1&1&3\\
1&2&-1&2
\end{array}
\right).$$

第二行减去第一行的 2 倍，第三行减去第一行：

$$\left(
\begin{array}{ccc|c}
1&1&1&6\\
0&-3&-1&-9\\
0&1&-2&-4
\end{array}
\right).$$

交换第二、三行，再把新的第二行乘以 $-1$：

$$\left(
\begin{array}{ccc|c}
1&1&1&6\\
0&1&-2&-4\\
0&-3&-1&-9
\end{array}
\right).$$

第三行加上第二行的 3 倍：

$$\left(
\begin{array}{ccc|c}
1&1&1&6\\
0&1&-2&-4\\
0&0&-7&-21
\end{array}
\right).$$

第三行给出 $-7z=-21$，所以 $z=3$。回代：$y-2\cdot 3=-4$，得 $y=2$；$x+2+3=6$，得 $x=1$。解为

$$(x,y,z)=(1,2,3).$$

这一组主元在三个不同的列上，对应唯一解。

## 4. 秩与解的结构

矩阵 $\mathbf{A}$ 的**秩** $\operatorname{rank}(\mathbf{A})$ 是行阶梯形中主元的个数，也就是非零行的个数。它衡量矩阵“真正独立的方向”有多少。

设方程组有 $n$ 个未知数，$\mathbf{A}$ 是 $m\times n$ 矩阵，$r=\operatorname{rank}(\mathbf{A})$。比较 $\operatorname{rank}(\mathbf{A})$ 与 $\operatorname{rank}([\mathbf{A}\mid\mathbf{b}])$：

| 情况 | 解的结构 |
|---|---|
| $\operatorname{rank}(\mathbf{A})<\operatorname{rank}([\mathbf{A}\mid\mathbf{b}])$ | 无解 |
| 两者相等，且 $r=n$ | 唯一解 |
| 两者相等，且 $r<n$ | 无穷多解，有 $n-r$ 个自由变量 |

直观解释：

- 增广矩阵的秩更大，说明出现了 $0=d$ 且 $d\ne 0$ 的矛盾行，方程组不相容；
- 每个未知数都对应一个主元，就没有自由变量，解唯一；
- 有 $n-r$ 列没有主元，这些列对应的变量可以自由取值，其他变量由它们决定。

**例 3.2**　

$$
\begin{cases}
x+2y+z=1,\\
2x+4y+z=3,\\
x+2y-z=3.
\end{cases}
$$

消元后得到

$$\left(
\begin{array}{ccc|c}
1&2&1&1\\
0&0&-1&1\\
0&0&0&0
\end{array}
\right).$$

秩为 2，未知数 3 个，所以有无穷多解。由第二行 $z=-1$，代入第一行得 $x=2-2y$。令 $y=t$，则

$$(x,y,z)=(2-2t,\ t,\ -1),\qquad t\in\mathbb{R}.$$

几何上，这是三维空间中的一条直线。

## 5. 齐次方程组与零空间

常数项全为 0 的方程组 $\mathbf{A}\mathbf{x}=\mathbf{0}$ 叫**齐次方程组**。它永远有零解 $\mathbf{x}=\mathbf{0}$，所以一定相容。

它的全部解组成矩阵 $\mathbf{A}$ 的**零空间**（null space），记作 $N(\mathbf{A})$：

$$N(\mathbf{A})=\{\mathbf{x}\in\mathbb{R}^n\mid \mathbf{A}\mathbf{x}=\mathbf{0}\}.$$

若 $\operatorname{rank}(\mathbf{A})=r$，则零空间的维数是 $n-r$。这个数叫**零化度**。

**例 3.3**　求

$$\mathbf{A}=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$$

的零空间。

第二行是第一行的 2 倍，消元后只剩 $x_1+2x_2+3x_3=0$。$x_2,x_3$ 是自由变量，令 $x_2=s$，$x_3=t$，则 $x_1=-2s-3t$。于是

$$\mathbf{x}=s\begin{pmatrix}-2\\1\\0\end{pmatrix}+t\begin{pmatrix}-3\\0\\1\end{pmatrix}.$$

零空间是二维平面，基为 $(-2,1,0)^\top$ 和 $(-3,0,1)^\top$。

> **连接**：非齐次方程 $\mathbf{A}\mathbf{x}=\mathbf{b}$ 的通解，等于“一个特解 + 齐次方程的通解”。这与微积分里“非齐次线性微分方程的通解 = 特解 + 齐次通解”是同一个结构。

## 6. 工程视角：约束与平衡

线性方程组在工程里通常不是“作业题”，而是约束：

- 无人机的力/力矩平衡：每个电机推力是未知数，机体受力平衡给出线性方程；
- 电路网络：基尔霍夫定律给出节点电流和回路电压的线性方程；
- 结构力学：桁架节点的受力平衡；
- 机器学习：线性回归的正规方程 $\mathbf{A}^\top\mathbf{A}\mathbf{x}=\mathbf{A}^\top\mathbf{b}$；
- 计算机视觉：多视图几何中的三角化与光束法平差。

工程中常见的三种情形正好对应上面的分类：

- **唯一解**：约束足够且独立，问题适定；
- **无穷多解**：约束不足，需要额外正则化或选一个最优解；
- **无解**：约束矛盾，通常说明模型有噪声，此时退而求最小二乘解（第 05 课）。

> **小实验**：用 NumPy 判断方程组是否有解，并求一个特解。

```python
import numpy as np

A = np.array([[1, 2, 1],
              [2, 4, 1],
              [1, 2, -1]])
b = np.array([1, 3, -1])
print(np.linalg.matrix_rank(A), np.linalg.matrix_rank(np.column_stack([A, b])))
print(np.linalg.lstsq(A, b, rcond=None)[0])  # 无穷多解时给出最小范数解
```

## 7. 练习

1. 解方程组
$\begin{cases}2x+y=5,\\x-y=1.\end{cases}$

2. 解方程组
$\begin{cases}x+y+z=3,\\2x+2y+2z=6,\\x-y=0.\end{cases}$

3. 求 $\mathbf{A}=\begin{pmatrix}1&2&3\\2&4&6\end{pmatrix}$ 的秩和零空间维数。

4. 讨论 $k$ 取何值时，方程组
$\begin{cases}x+y=2,\\2x+2y=k\end{cases}$
有唯一解、无穷多解或无解。

5. 判断方程组
$\begin{cases}x+y=1,\\x+y=2\end{cases}$
是否有解，并用秩解释。

---

## 8. 答案与简解

<details>
<summary>点击展开（做完再看）</summary>

**1.** 第二式给出 $x=y+1$，代入第一式：$2(y+1)+y=5$，即 $3y=3$，$y=1$，$x=2$。解为 $(2,1)$。

**2.** 第二行是第一行的 2 倍，方程实际只有 $x+y+z=3$ 和 $x-y=0$。由 $x=y$ 得 $2y+z=3$，即 $z=3-2y$。令 $y=t$，解为

$$(x,y,z)=(t,t,3-2t).$$

**3.** 第二行是第一行的 2 倍，秩为 1，零空间维数为 $3-1=2$。零空间由 $x_1+2x_2+3x_3=0$ 给出，基为 $(-2,1,0)^\top$、$(-3,0,1)^\top$。

**4.** 第二式是 $2(x+y)=k$。若 $k=4$，与第一式相容，但两式成比例，秩为 1，未知数 2 个，有无穷多解；若 $k\ne 4$，则 $x+y=2$ 与 $x+y=k/2$ 矛盾，无解。不存在唯一解的情形，因为两行总是成比例。

**5.** 增广矩阵消元后出现 $0=1$，无解。$\operatorname{rank}(\mathbf{A})=1$，而 $\operatorname{rank}([\mathbf{A}\mid\mathbf{b}])=2$，增广矩阵的秩更大。

</details>
