## 1. 内积、范数与夹角

两个 $n$ 维向量的**内积**定义为

$$\mathbf{a}\cdot\mathbf{b}=\mathbf{a}^\top\mathbf{b}
=\sum_{i=1}^n a_i b_i.$$

它是标量，不是向量。内积满足对称性和线性性：

$$\mathbf{a}\cdot\mathbf{b}=\mathbf{b}\cdot\mathbf{a},\qquad
\mathbf{a}\cdot(c\mathbf{b}+d\mathbf{c})=c\,\mathbf{a}\cdot\mathbf{b}+d\,\mathbf{a}\cdot\mathbf{c}.$$

由内积定义**范数**（长度）：

$$\|\mathbf{a}\|=\sqrt{\mathbf{a}\cdot\mathbf{a}}
=\sqrt{a_1^2+\cdots+a_n^2}.$$

两个非零向量的夹角 $\theta$ 满足

$$\cos\theta=\frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}.$$

**Cauchy–Schwarz 不等式**给出

$$|\mathbf{a}\cdot\mathbf{b}|\le\|\mathbf{a}\|\|\mathbf{b}\|,$$

所以 $|\cos\theta|\le 1$，夹角定义是自洽的。

> **注意**：不要把内积和逐元素乘积混淆。逐元素乘积 $a_i b_i$ 仍是一个向量，内积要把所有分量加起来。

## 2. 正交与标准正交基

若 $\mathbf{a}\cdot\mathbf{b}=0$，称两向量**正交**，记作 $\mathbf{a}\perp\mathbf{b}$。几何上就是夹角为 $90^\circ$。

一组向量若两两正交，且每个向量长度为 1，称为**标准正交组**。若它们还能张成整个空间，就是**标准正交基**。

标准正交基的最大好处是坐标容易求。若 $\mathbf{q}_1,\dots,\mathbf{q}_n$ 是标准正交基，则任意向量 $\mathbf{v}$ 可以写成

$$\mathbf{v}=\sum_{i=1}^n (\mathbf{q}_i\cdot\mathbf{v})\,\mathbf{q}_i.$$

系数就是内积，不需要解方程组。这正是傅里叶级数、QR 分解和 PCA 都在寻找正交基的原因。

## 3. 投影到直线与子空间

**投影到直线**：把 $\mathbf{v}$ 投影到非零向量 $\mathbf{u}$ 张成的直线上，投影点为

$$\operatorname{proj}_{\mathbf{u}}\mathbf{v}
=\frac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{u}\cdot\mathbf{u}}\,\mathbf{u}.$$

标量系数 $\dfrac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{u}\cdot\mathbf{u}}$ 是 $\mathbf{v}$ 在 $\mathbf{u}$ 方向上的坐标。残差

$$\mathbf{v}-\operatorname{proj}_{\mathbf{u}}\mathbf{v}$$

与 $\mathbf{u}$ 正交，这是投影的定义性质。

**例 5.1**　把 $\mathbf{v}=(1,2,3)$ 投影到 $\mathbf{u}=(1,1,1)$ 张成的直线上。

$$\mathbf{u}\cdot\mathbf{v}=1+2+3=6,\qquad
\mathbf{u}\cdot\mathbf{u}=3,$$

所以

$$\operatorname{proj}_{\mathbf{u}}\mathbf{v}=\frac{6}{3}(1,1,1)=(2,2,2).$$

残差为 $(-1,0,1)$，与 $(1,1,1)$ 的内积为 $-1+0+1=0$，确实正交。

**投影到子空间**：若子空间由矩阵 $\mathbf{A}$ 的列张成，且各列线性无关，则投影矩阵为

$$\mathbf{P}=\mathbf{A}(\mathbf{A}^\top\mathbf{A})^{-1}\mathbf{A}^\top.$$

对任意 $\mathbf{b}$，$\mathbf{P}\mathbf{b}$ 是 $\mathbf{b}$ 在列空间中的正交投影。投影矩阵满足 $\mathbf{P}^2=\mathbf{P}$ 和 $\mathbf{P}^\top=\mathbf{P}$。

## 4. Gram–Schmidt 与 QR

给定一组线性无关的向量 $\mathbf{a}_1,\dots,\mathbf{a}_n$，Gram–Schmidt 过程逐个构造正交基：

$$
\begin{aligned}
\mathbf{q}_1&=\frac{\mathbf{a}_1}{\|\mathbf{a}_1\|},\\
\mathbf{w}_2&=\mathbf{a}_2-(\mathbf{q}_1\cdot\mathbf{a}_2)\mathbf{q}_1,\qquad
\mathbf{q}_2=\frac{\mathbf{w}_2}{\|\mathbf{w}_2\|},\\
\mathbf{w}_3&=\mathbf{a}_3-(\mathbf{q}_1\cdot\mathbf{a}_3)\mathbf{q}_1
-(\mathbf{q}_2\cdot\mathbf{a}_3)\mathbf{q}_2,\qquad
\mathbf{q}_3=\frac{\mathbf{w}_3}{\|\mathbf{w}_3\|}.
\end{aligned}
$$

每一步都减去前面已经得到的正交方向上的分量，剩下的自然与前面的向量正交。

把过程写成矩阵形式，就得到 **QR 分解**：

$$\mathbf{A}=\mathbf{Q}\mathbf{R},$$

其中 $\mathbf{Q}$ 的列是标准正交基，$\mathbf{R}$ 是上三角矩阵。QR 分解比正规方程数值更稳定，是求解最小二乘的常用方法。

## 5. 最小二乘与正规方程

当 $\mathbf{A}\mathbf{x}=\mathbf{b}$ 无解时，我们退而求其次：找一个 $\mathbf{x}$，使残差

$$\mathbf{r}=\mathbf{b}-\mathbf{A}\mathbf{x}$$

的范数最小。这就是**最小二乘**问题：

$$\hat{\mathbf{x}}=\arg\min_{\mathbf{x}}\|\mathbf{A}\mathbf{x}-\mathbf{b}\|^2.$$

几何上，$\mathbf{A}\hat{\mathbf{x}}$ 是 $\mathbf{b}$ 在列空间 $C(\mathbf{A})$ 上的正交投影。因此残差 $\mathbf{b}-\mathbf{A}\hat{\mathbf{x}}$ 必须与列空间正交：

$$\mathbf{A}^\top(\mathbf{b}-\mathbf{A}\hat{\mathbf{x}})=\mathbf{0}.$$

整理得到**正规方程**：

$$\mathbf{A}^\top\mathbf{A}\,\hat{\mathbf{x}}=\mathbf{A}^\top\mathbf{b}.$$

若 $\mathbf{A}$ 的列线性无关，$\mathbf{A}^\top\mathbf{A}$ 可逆，解为

$$\hat{\mathbf{x}}=(\mathbf{A}^\top\mathbf{A})^{-1}\mathbf{A}^\top\mathbf{b}.$$

**例 5.2**　用直线 $y=c+dx$ 拟合三个点 $(0,1)$、$(1,2)$、$(2,4)$。

把模型写成矩阵形式：

$$\mathbf{A}=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix},\qquad
\mathbf{b}=\begin{pmatrix}1\\2\\4\end{pmatrix},\qquad
\mathbf{x}=\begin{pmatrix}c\\d\end{pmatrix}.$$

计算

$$\mathbf{A}^\top\mathbf{A}=
\begin{pmatrix}3&3\\3&5\end{pmatrix},\qquad
\mathbf{A}^\top\mathbf{b}=
\begin{pmatrix}7\\10\end{pmatrix}.$$

正规方程为

$$
\begin{cases}
3c+3d=7,\\
3c+5d=10.
\end{cases}
$$

两式相减得 $2d=3$，所以 $d=\dfrac32$，再得 $c=\dfrac56$。拟合直线为

$$y=\frac56+\frac32x.$$

三个点的预测值约为 $0.833$、$2.333$、$3.833$，残差为 $0.167$、$-0.333$、$0.167$，满足残差与两列都正交。

## 6. 工程视角：标定、SLAM 与过定系统

最小二乘是工程里出现频率最高的数学工具之一：

- **传感器标定**：用多组已知输入输出拟合校准参数，方程数多于未知数；
- **SLAM / 视觉里程计**：大量观测约束同一个位姿，需要最小化重投影误差；
- **系统辨识**：用实验数据估计动力学参数；
- **机器学习**：线性回归、神经网络训练本质上都是最小化残差平方和；
- **信号处理**：滤波、拟合、压缩感知都离不开投影。

工程数据几乎总是“过定”的：方程比未知数多，而且有噪声。此时不要问“为什么无解”，而要问“哪个解让残差最小”。这就是最小二乘的出发点。

> **小实验**：用 NumPy 解上面的拟合问题，并检查残差是否与列空间正交。

```python
import numpy as np

A = np.array([[1, 0], [1, 1], [1, 2]], dtype=float)
b = np.array([1, 2, 4], dtype=float)
x, *_ = np.linalg.lstsq(A, b, rcond=None)
print(x)                 # [0.8333, 1.5]
print(A.T @ (b - A @ x)) # 接近 [0, 0]
```

## 7. 练习

1. 求 $\mathbf{a}=(1,2,2)$ 的范数，以及它与 $\mathbf{b}=(2,-1,0)$ 的夹角余弦。

2. 把 $\mathbf{v}=(3,4)$ 投影到 $\mathbf{u}=(1,0)$ 张成的直线上。

3. 用直线 $y=c+dx$ 拟合点 $(0,0)$、$(1,1)$、$(2,2)$，求 $c,d$。

4. 对 $\mathbf{a}_1=(1,1,0)$、$\mathbf{a}_2=(1,0,1)$ 做 Gram–Schmidt，求标准正交基。

5. 解释为什么最小二乘的残差一定与 $\mathbf{A}$ 的列空间正交。

## 8. 答案与简解

<details>
<summary>点击展开（做完再看）</summary>

**1.** $\|\mathbf{a}\|=\sqrt{1+4+4}=3$，$\mathbf{a}\cdot\mathbf{b}=2-2+0=0$，所以夹角余弦为 0，两向量正交。

**2.** 投影为 $\dfrac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{u}\cdot\mathbf{u}}\mathbf{u}
=\dfrac{3}{1}(1,0)=(3,0)$。

**3.** $\mathbf{A}=\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}$，$\mathbf{b}=(0,1,2)^\top$。

$$\mathbf{A}^\top\mathbf{A}=\begin{pmatrix}3&3\\3&5\end{pmatrix},\qquad
\mathbf{A}^\top\mathbf{b}=\begin{pmatrix}3\\5\end{pmatrix}.$$

解得 $c=0$，$d=1$，即 $y=x$。三个点正好共线，残差为零。

**4.** $\mathbf{q}_1=\dfrac{1}{\sqrt2}(1,1,0)$。
$\mathbf{q}_1\cdot\mathbf{a}_2=\dfrac{1}{\sqrt2}$，
$\mathbf{w}_2=(1,0,1)-\dfrac12(1,1,0)=\left(\dfrac12,-\dfrac12,1\right)$。
$\|\mathbf{w}_2\|=\sqrt{\dfrac14+\dfrac14+1}=\sqrt{\dfrac32}$，
所以 $\mathbf{q}_2=\sqrt{\dfrac23}\left(\dfrac12,-\dfrac12,1\right)$。

**5.** 因为 $\mathbf{A}\hat{\mathbf{x}}$ 是 $\mathbf{b}$ 在列空间上的正交投影，而残差是 $\mathbf{b}$ 减去投影，所以残差落在列空间的正交补中，与列空间中每个向量都正交。写成式子就是 $\mathbf{A}^\top(\mathbf{b}-\mathbf{A}\hat{\mathbf{x}})=\mathbf{0}$。
