1. 极限的直觉

以前学函数，问的是：x = 1 时，f(x) 等于多少？

极限问的是：x 靠近 1 时，f(x) 靠近多少？

看一个例子：

f(x)=x2−1x−1

x = 1 时没有定义（分母为 0）。但可以看它附近的取值：

x 1.1 1.01 1.001 0.999 0.99
f(x) 2.1 2.01 2.001 1.999 1.99

x 越靠近 1，f(x) 越靠近 2。记作：

limx→1x2−1x−1=2

核心一句话：极限与那一点函数值无关，只看那一点附近。

这就是极限比"直接代入"强的地方：代入算不出来的，极限可能算得出来。

2. 两个基本事实

事实一：

limx→ax=a,limx→aC=C(C 为常数)

事实二：极限可以加减乘除（分母极限不为 0 时）：

lim(f±g)=limf±limg
lim(f·g)=limf·limg
limfg=limflimg(limg≠0)

3. 四步计算法

做题时按顺序检查，命中哪一步就用哪一步。

第一步：直接代入

能算出数，就是答案。

limx→2(x2+1)=22+1=5

第二步：代入得 0/0 → 约掉零因子

因式分解：

limx→1x2−1x−1=limx→1(x−1)(x+1)x−1=limx→1(x+1)=2

有理化（带根号时，分子分母同乘共轭）：

limx→01+x−1x

分子分母同乘 1+x+1：

=limx→0(1+x−1)(1+x+1)x(1+x+1)=limx→0xx(1+x+1)=limx→011+x+1=12

第三步：x → ∞ 时，分子分母同除最高次幂

limx→∞3x2+xx2−1=limx→∞3+1x1−1x2=3+01−0=3

口诀：

情况 结果
分母次数更高 极限为 0
分子次数更高 极限为 ∞
次数相同 最高次项系数之比

第四步：x → 0 的三角／指数型，用等价无穷小

limx→0sin5xsin2x=limx→05x2x=52
limx→01−cosxx2=limx→0x22x2=12

4. 等价无穷小（仅当 x → 0）

原式 等价于
sinx x
tanx x
1−cosx x22
ln(1+x) x
ex−1 x

使用规则：

  • 只能在乘除中替换
  • 加减中不要随便替换，容易出错
  • 只适用于 x→0，别的趋向不能直接用

5. 易错点

  1. 0/0 不是答案，是"继续算"的信号。
  2. x → ∞ 才同除最高次；x → 某一点时不用这招。
  3. 等价无穷小只适用于 x → 0，且只在乘除里用。
  4. 有理化时别漏乘分母，分子分母必须同时乘。
