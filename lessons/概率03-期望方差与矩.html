1. 期望与 LOTUS

离散型随机变量的期望是加权平均：

𝔼[X]=∑xxpX(x).

连续型用积分：

𝔼[X]=∫−∞∞xfX(x)dx.

期望描述“长期平均会落在哪里”，不一定是可能取值。例如掷骰子的期望是 3.5，但骰子不会掷出 3.5。

LOTUS（无意识统计学家法则）：对任意函数 g，

𝔼[g(X)]=∑xg(x)pX(x)

或

𝔼[g(X)]=∫−∞∞g(x)fX(x)dx.

关键是：不需要先求 g(X) 的分布，直接对 X 的分布加权即可。

2. 期望的性质

期望是线性的：

𝔼[aX+bY+c]=a𝔼[X]+b𝔼[Y]+c.

这条性质不要求 X,Y 独立，非常重要。

若 X,Y 独立，则

𝔼[XY]=𝔼[X]𝔼[Y].

反之不成立：𝔼[XY]=𝔼[X]𝔼[Y] 不能推出独立。

若 X≥0，则 𝔼[X]≥0；若 a≤X≤b，则 a≤𝔼[X]≤b。

3. 方差与标准差

方差衡量随机变量围绕期望的波动：

Var(X)=𝔼[(X−𝔼[X])2].

展开得常用公式：

Var(X)=𝔼[X2]−(𝔼[X])2.

标准差是方差的平方根：

σX=Var(X).

标准差与 X 同量纲，比方差更直观。

性质：

Var(aX+b)=a2Var(X),
Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y).

若 X,Y 独立，协方差为 0，方差直接相加。

例 3.1　设 X~B(n,p)。把 X 写成 n 个独立伯努利变量之和：

X=X1+⋯+Xn,Xi~Bern(p).

则

𝔼[X]=np,Var(X)=np(1−p).

用“和的方差等于方差之和”比直接求和式的平方简单得多。

4. 协方差与相关系数

协方差衡量两个变量的线性联动：

Cov(X,Y)=𝔼[(X−𝔼X)(Y−𝔼Y)]=𝔼[XY]−𝔼[X]𝔼[Y].

若 X,Y 独立，则 Cov(X,Y)=0；反之不一定。协方差为 0 只说明没有线性相关，可能存在非线性关系。

相关系数是归一化的协方差：

ρXY=Cov(X,Y)σXσY.

它满足 −1≤ρXY≤1。ρ=1 表示完全正线性相关，ρ=−1 表示完全负线性相关，ρ=0 称为不相关。

注意：不相关 ≠ 独立。例如 X~U(−1,1)，Y=X2，则 Cov(X,Y)=𝔼[X3]=0，但 Y 完全由 X 决定。

5. 矩与矩母函数

原点矩：𝔼[Xk]；中心矩：𝔼[(X−𝔼X)k]。

  • 一阶原点矩是期望；
  • 二阶中心矩是方差；
  • 三阶中心矩描述偏度（不对称性）；
  • 四阶中心矩描述峰度（尾部厚度）。

矩母函数定义为

MX(t)=𝔼[etX],

在 t=0 附近存在时，满足

MX(k)(0)=𝔼[Xk].

它把求矩变成求导。独立随机变量之和的矩母函数等于各自矩母函数的乘积，因此常用来证明分布的可加性。

6. 三个常用不等式

Markov 不等式：若 X≥0，a>0，则

P(X≥a)≤𝔼[X]a.

Chebyshev 不等式：对任意 k>0，

P(|X−𝔼X|≥kσ)≤1k2.

等价地，P(|X−μ|≥ε)≤σ2ε2。

它说明：偏离均值超过 k 个标准差的概率不超过 1/k2。虽然界通常很松，但不需要知道具体分布。

Jensen 不等式：若 g 是凸函数，则

g(𝔼[X])≤𝔼[g(X)].

例如 g(x)=x2 给出 (𝔼X)2≤𝔼[X2]，即方差非负。

7. 工程视角：误差传播与信噪比

  • 误差传播：若 Y=f(X)，用一阶泰勒展开近似
Var(Y)≈[f′(𝔼X)]2Var(X).

这是传感器误差分析的基本公式。 - 信噪比：SNR=𝔼[S2]𝔼[N2]，用二阶矩比较信号与噪声。 - 滤波：卡尔曼滤波的协方差传播就是“和的方差”和“线性变换的方差”的反复应用。 - 风险评估：期望收益相同，方差大的方案风险更高；夏普比率用均值/标准差衡量单位风险的收益。

小实验：用样本估计均值和方差，观察大数定律的效果。

import numpy as np

x = np.random.normal(loc=3, scale=2, size=100000)
print(x.mean(), x.var(ddof=1))
