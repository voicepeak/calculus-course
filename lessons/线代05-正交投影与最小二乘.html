1. 内积、范数与夹角

两个 n 维向量的内积定义为

𝐚·𝐛=𝐚⊤𝐛=∑i=1naibi.

它是标量，不是向量。内积满足对称性和线性性：

𝐚·𝐛=𝐛·𝐚,𝐚·(c𝐛+d𝐜)=c𝐚·𝐛+d𝐚·𝐜.

由内积定义范数（长度）：

‖𝐚‖=𝐚·𝐚=a12+⋯+an2.

两个非零向量的夹角 θ 满足

cosθ=𝐚·𝐛‖𝐚‖‖𝐛‖.

Cauchy–Schwarz 不等式给出

|𝐚·𝐛|≤‖𝐚‖‖𝐛‖,

所以 |cosθ|≤1，夹角定义是自洽的。

注意：不要把内积和逐元素乘积混淆。逐元素乘积 aibi 仍是一个向量，内积要把所有分量加起来。

2. 正交与标准正交基

若 𝐚·𝐛=0，称两向量正交，记作 𝐚⟂𝐛。几何上就是夹角为 90∘。

一组向量若两两正交，且每个向量长度为 1，称为标准正交组。若它们还能张成整个空间，就是标准正交基。

标准正交基的最大好处是坐标容易求。若 𝐪1,…,𝐪n 是标准正交基，则任意向量 𝐯 可以写成

𝐯=∑i=1n(𝐪i·𝐯)𝐪i.

系数就是内积，不需要解方程组。这正是傅里叶级数、QR 分解和 PCA 都在寻找正交基的原因。

3. 投影到直线与子空间

投影到直线：把 𝐯 投影到非零向量 𝐮 张成的直线上，投影点为

proj𝐮𝐯=𝐮·𝐯𝐮·𝐮𝐮.

标量系数 𝐮·𝐯𝐮·𝐮 是 𝐯 在 𝐮 方向上的坐标。残差

𝐯−proj𝐮𝐯

与 𝐮 正交，这是投影的定义性质。

例 5.1　把 𝐯=(1,2,3) 投影到 𝐮=(1,1,1) 张成的直线上。

𝐮·𝐯=1+2+3=6,𝐮·𝐮=3,

所以

proj𝐮𝐯=63(1,1,1)=(2,2,2).

残差为 (−1,0,1)，与 (1,1,1) 的内积为 −1+0+1=0，确实正交。

投影到子空间：若子空间由矩阵 𝐀 的列张成，且各列线性无关，则投影矩阵为

𝐏=𝐀(𝐀⊤𝐀)−1𝐀⊤.

对任意 𝐛，𝐏𝐛 是 𝐛 在列空间中的正交投影。投影矩阵满足 𝐏2=𝐏 和 𝐏⊤=𝐏。

4. Gram–Schmidt 与 QR

给定一组线性无关的向量 𝐚1,…,𝐚n，Gram–Schmidt 过程逐个构造正交基：

𝐪1&=𝐚1‖𝐚1‖,𝐰2&=𝐚2−(𝐪1·𝐚2)𝐪1,𝐪2=𝐰2‖𝐰2‖,𝐰3&=𝐚3−(𝐪1·𝐚3)𝐪1−(𝐪2·𝐚3)𝐪2,𝐪3=𝐰3‖𝐰3‖.

每一步都减去前面已经得到的正交方向上的分量，剩下的自然与前面的向量正交。

把过程写成矩阵形式，就得到 QR 分解：

𝐀=𝐐𝐑,

其中 𝐐 的列是标准正交基，𝐑 是上三角矩阵。QR 分解比正规方程数值更稳定，是求解最小二乘的常用方法。

5. 最小二乘与正规方程

当 𝐀𝐱=𝐛 无解时，我们退而求其次：找一个 𝐱，使残差

𝐫=𝐛−𝐀𝐱

的范数最小。这就是最小二乘问题：

𝐱^=\argmin𝐱‖𝐀𝐱−𝐛‖2.

几何上，𝐀𝐱^ 是 𝐛 在列空间 C(𝐀) 上的正交投影。因此残差 𝐛−𝐀𝐱^ 必须与列空间正交：

𝐀⊤(𝐛−𝐀𝐱^)=0.

整理得到正规方程：

𝐀⊤𝐀𝐱^=𝐀⊤𝐛.

若 𝐀 的列线性无关，𝐀⊤𝐀 可逆，解为

𝐱^=(𝐀⊤𝐀)−1𝐀⊤𝐛.

例 5.2　用直线 y=c+dx 拟合三个点 (0,1)、(1,2)、(2,4)。

把模型写成矩阵形式：

𝐀=(101112),𝐛=(124),𝐱=(cd).

计算

𝐀⊤𝐀=(3335),𝐀⊤𝐛=(710).

正规方程为

{3c+3d=7,3c+5d=10.

两式相减得 2d=3，所以 d=32，再得 c=56。拟合直线为

y=56+32x.

三个点的预测值约为 0.833、2.333、3.833，残差为 0.167、−0.333、0.167，满足残差与两列都正交。

6. 工程视角：标定、SLAM 与过定系统

最小二乘是工程里出现频率最高的数学工具之一：

  • 传感器标定：用多组已知输入输出拟合校准参数，方程数多于未知数；
  • SLAM / 视觉里程计：大量观测约束同一个位姿，需要最小化重投影误差；
  • 系统辨识：用实验数据估计动力学参数；
  • 机器学习：线性回归、神经网络训练本质上都是最小化残差平方和；
  • 信号处理：滤波、拟合、压缩感知都离不开投影。

工程数据几乎总是“过定”的：方程比未知数多，而且有噪声。此时不要问“为什么无解”，而要问“哪个解让残差最小”。这就是最小二乘的出发点。

小实验：用 NumPy 解上面的拟合问题，并检查残差是否与列空间正交。

import numpy as np

A = np.array([[1, 0], [1, 1], [1, 2]], dtype=float)
b = np.array([1, 2, 4], dtype=float)
x, *_ = np.linalg.lstsq(A, b, rcond=None)
print(x)                 # [0.8333, 1.5]
print(A.T @ (b - A @ x)) # 接近 [0, 0]

7. 练习

  1. 求 𝐚=(1,2,2) 的范数，以及它与 𝐛=(2,−1,0) 的夹角余弦。

  2. 把 𝐯=(3,4) 投影到 𝐮=(1,0) 张成的直线上。

  3. 用直线 y=c+dx 拟合点 (0,0)、(1,1)、(2,2)，求 c,d。

  4. 对 𝐚1=(1,1,0)、𝐚2=(1,0,1) 做 Gram–Schmidt，求标准正交基。

  5. 解释为什么最小二乘的残差一定与 𝐀 的列空间正交。

8. 答案与简解

点击展开（做完再看） **1.** ‖𝐚‖=1+4+4=3，𝐚·𝐛=2−2+0=0，所以夹角余弦为 0，两向量正交。 **2.** 投影为 $\dfrac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{u}\cdot\mathbf{u}}\mathbf{u} =\dfrac{3}{1}(1,0)=(3,0)$。 **3.** 𝐀=(101112)，𝐛=(0,1,2)⊤。
𝐀⊤𝐀=(3335),𝐀⊤𝐛=(35).
解得 c=0，d=1，即 y=x。三个点正好共线，残差为零。 **4.** 𝐪1=12(1,1,0)。 𝐪1·𝐚2=12， 𝐰2=(1,0,1)−12(1,1,0)=(12,−12,1)。 ‖𝐰2‖=14+14+1=32， 所以 𝐪2=23(12,−12,1)。 **5.** 因为 𝐀𝐱^ 是 𝐛 在列空间上的正交投影，而残差是 𝐛 减去投影，所以残差落在列空间的正交补中，与列空间中每个向量都正交。写成式子就是 𝐀⊤(𝐛−𝐀𝐱^)=0。
