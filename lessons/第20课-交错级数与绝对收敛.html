本课目标：掌握莱布尼茨判别法，分清绝对收敛与条件收敛，会用交错级数估计误差。

1. 交错级数

各项符号正负交替的级数，称为交错级数。常见形式：

∑n=1∞(−1)n−1an=a1−a2+a3−a4+⋯

或

∑n=1∞(−1)nan=−a1+a2−a3+a4−⋯

其中 an>0。

例如：

1−12+13−14+⋯=∑n=1∞(−1)n−1n

这是交错调和级数。

2. 莱布尼茨判别法

莱布尼茨判别法：如果交错级数

∑n=1∞(−1)n−1an

满足

  1. an>0；
  2. an+1≤an（从某一项开始单调不增）；
  3. limn→∞an=0；

那么该级数收敛。

直观理解：正负项互相抵消，而且每次抵消的幅度越来越小，部分和在两个值之间来回摆动，最终稳定下来。

例 1：

∑n=1∞(−1)n−1n=1−12+13−14+⋯

满足 an=1n>0，单调递减，且趋于 0，所以收敛。

它的和是

ln2≈0.6931

例 2：

∑n=1∞(−1)n−1n

an=1n>0，单调递减，且趋于 0，所以收敛。

注意：莱布尼茨判别法是充分条件，不是必要条件。不满足它的交错级数也可能收敛，只是不能用它来判断。

反例提醒：如果只满足 an→0，但 an 不单调，莱布尼茨判别法不能直接用。例如适当打乱正负项的顺序，可能改变收敛性。

3. 交错级数的误差估计

设

S=∑n=1∞(−1)n−1an

满足莱布尼茨条件， SN 是前 N 项部分和。那么

|S−SN|≤aN+1

并且余项的符号与第一个被省略的项相同。

意义：用前 N 项近似整个级数的和，误差不超过下一项的绝对值。

例：用前 4 项近似

S=∑n=1∞(−1)n−1n

即

S4=1−12+13−14=712≈0.5833

误差不超过

a5=15=0.2

实际值 ln2≈0.6931，误差约为

0.6931−0.5833=0.1098<0.2

应用：如果要保证误差小于 0.01，只需

aN+1=1N+1<0.01⇒N+1>100⇒N≥100

所以取前 100 项即可。

4. 绝对收敛

定义：如果级数

∑n=1∞an

的绝对值级数

∑n=1∞|an|

收敛，则称原级数绝对收敛。

定理：绝对收敛的级数一定收敛。

证明思路：设 ∑|an| 收敛。因为

0≤an+|an|≤2|an|

由比较判别法， ∑(an+|an|) 收敛。于是

∑an=∑(an+|an|)−∑|an|

是两个收敛级数之差，所以也收敛。

例 1：

∑n=1∞(−1)n−1n2

绝对值级数

∑n=1∞1n2

是 p=2 的 p-级数，收敛。所以原级数绝对收敛。

例 2：

∑n=1∞(−1)nn!

绝对值级数

∑n=1∞1n!

收敛（比值判别法： 1n+1→0）。所以原级数绝对收敛。

绝对收敛的好处：可以任意交换项的顺序而不改变和，也可以像普通和一样做加法、乘法。

5. 条件收敛

定义：如果级数 ∑an 收敛，但绝对值级数 ∑|an| 发散，则称原级数条件收敛。

例 1：

∑n=1∞(−1)n−1n

原级数收敛（莱布尼茨判别法），但

∑n=1∞1n

是调和级数，发散。所以原级数条件收敛。

例 2：

∑n=1∞(−1)n−1n

原级数收敛，但

∑n=1∞1n

是 p=12 的 p-级数，发散。所以原级数条件收敛。

重要区别：

类型 原级数 绝对值级数 能否重排
绝对收敛 收敛 收敛 可以任意重排，和不变
条件收敛 收敛 发散 不能随意重排，和可能改变

注意：条件收敛的级数虽然收敛，但“收敛得很勉强”，对项的顺序很敏感。

6. 判别流程

拿到一个级数 ∑an，按以下顺序判断：

第一步：通项检验

如果 an 不趋于 0，直接发散。

第二步：判断绝对值级数

对 ∑|an| 使用正项级数的判别法：

  • 收敛 ⇒ 原级数绝对收敛；
  • 发散 ⇒ 进入第三步。

第三步：看是否交错

如果是交错级数，尝试莱布尼茨判别法：

  • 满足条件 ⇒ 条件收敛（因为绝对值级数已发散）；
  • 不满足条件 ⇒ 需要其他方法，不能直接下结论。

第四步：其他方法

非交错、非绝对收敛的级数，可能需要更精细的判别法，本课程不展开。

7. 例题

例 1

判断

∑n=1∞(−1)nnn2+1

绝对值级数：

∑n=1∞nn2+1

通项约为 nn2=1n，与调和级数同敛散，发散。

原级数：令

an=nn2+1

先看单调性。令

f(x)=xx2+1

则

f′(x)=(x2+1)−x·2x(x2+1)2=1−x2(x2+1)2

当 x>1 时， f′(x)<0，所以 an 从 n=2 起单调递减。

又

an=nn2+1→0

由莱布尼茨判别法，原级数收敛。

结合绝对值级数发散，原级数条件收敛。

例 2

判断

∑n=1∞(−1)n(nn+1)n

先看通项：

(nn+1)n=1(1+1n)n→1e≠0

通项不趋于 0，所以级数发散。

教训：不要看到交错就直接用莱布尼茨判别法，先做通项检验。

例 3

判断

∑n=1∞(−1)n−1n!

绝对值级数

∑n=1∞1n!

用比值判别法：

1(n+1)!1n!=1n+1→0<1

所以绝对值级数收敛，原级数绝对收敛。

8. 易错点

  1. 莱布尼茨判别法必须先验证单调递减。只验证通项趋于 0 不够。
  2. 绝对收敛一定收敛，条件收敛只是收敛。两者不能混为一谈。
  3. 判断绝对收敛时，绝对值符号要加对。 (−1)n 的绝对值是 1，不是 −1。
  4. 条件收敛的级数不能随意重排。重排后可能收敛到不同的值，甚至发散。
  5. 交错级数的误差估计只用下一项，不要再乘系数。
  6. 通项不趋于 0 时，无论是否交错都发散。先做通项检验。
  7. ∑(−1)nan 和 ∑(−1)n−1an 只差一个负号，敛散性相同，和相差一个符号。
