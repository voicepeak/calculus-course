1. 对称矩阵与谱定理

若方阵满足 𝐀⊤=𝐀，称它为对称矩阵。对称矩阵在工程中极其常见：协方差矩阵、Hessian 矩阵、图的邻接矩阵、刚度矩阵都是对称的。

谱定理：实对称矩阵一定可以正交对角化。也就是说，存在正交矩阵 𝐐 和对角矩阵 Λ，使得

𝐀=𝐐Λ𝐐⊤,

其中 𝐐 的列是标准正交的特征向量，Λ 的对角线是对应的实特征值。

这个定理有三层含义：

  1. 实对称矩阵的特征值全是实数；
  2. 不同特征值对应的特征向量自动正交；
  3. 即使有重特征值，也能选出一组标准正交的特征向量。

因此对称矩阵是所有矩阵里“最听话”的一类，很多算法优先把问题化成对称形式。

2. 正交对角化

正交矩阵满足 𝐐⊤𝐐=𝐈，所以 𝐐−1=𝐐⊤。正交对角化就是把普通对角化中的 𝐏−1 换成 𝐐⊤：

𝐀=𝐐Λ𝐐⊤.

用特征向量展开，可以写成谱分解：

𝐀=∑i=1nλi𝐪i𝐪i⊤.

每一项 𝐪i𝐪i⊤ 是向 𝐪i 方向投影的矩阵。所以对称矩阵的作用可以理解为：先旋转到特征基，沿各轴独立缩放，再旋转回来。

3. 二次型

形如

Q(𝐱)=𝐱⊤𝐀𝐱=∑i,jaijxixj

的函数叫二次型。它是关于 x1,…,xn 的二次齐次多项式。

由于 𝐱⊤𝐀𝐱 只依赖 𝐀 的对称部分，总可以假设 𝐀 是对称矩阵。例如

𝐱⊤(1201)𝐱=x12+2x1x2+x22=𝐱⊤(1111)𝐱.

写成对称形式后，就可以用谱定理分析。

例 8.1　把

Q(x1,x2)=2x12+2x1x2+2x22

写成矩阵形式。

交叉项 2x1x2 对应矩阵的非对角元各取一半，所以

𝐀=(2112),Q=𝐱⊤𝐀𝐱.

4. 正定、半正定与判定

若对任意 𝐱≠0 都有

Q(𝐱)=𝐱⊤𝐀𝐱>0,

称 𝐀 正定，记作 𝐀≻0。若只要求 ≥0，称半正定，记作 𝐀⪰0。类似地有负定、半负定和不定。

判定方法：

  1. 特征值法：𝐀 正定 ⟺ 所有特征值 >0；半正定 ⟺ 所有特征值 ≥0。
  2. 顺序主子式法（Sylvester 判据）：𝐀 正定 ⟺ 所有顺序主子式都 >0。
  3. 配方/Cholesky：能把二次型化成平方和且系数全正，则正定。

例 8.1 的矩阵特征值为 3 和 1，都大于 0，所以正定。事实上

Q=(x1+x2)2+x12+x22>0(𝐱≠0).

而

𝐁=(100−1)

的特征值为 1 和 −1，不定：沿 x1 方向为正，沿 x2 方向为负。

5. Rayleigh 商与椭球

对对称矩阵 𝐀，定义 Rayleigh 商

R(𝐱)=𝐱⊤𝐀𝐱𝐱⊤𝐱,𝐱≠0.

它的最大值是最大特征值 λmax，最小值是最小特征值 λmin，分别在对应的特征向量处取到。

如果 𝐀 正定，方程

𝐱⊤𝐀𝐱=1

表示一个椭球。沿特征向量方向，椭球的半轴长度为

1λi.

特征值越大，该方向越短；特征值越小，该方向越长。这解释了为什么协方差矩阵的特征值小，表示那个方向的不确定性大。

例 8.2　对例 8.1 的 𝐀，在单位圆 x12+x22=1 上，Q 的最大值为 3，在 𝐪1=12(1,1) 处取到；最小值为 1，在 𝐪2=12(1,−1) 处取到。

6. Hessian、凸性与协方差

Hessian 矩阵是多元函数的二阶偏导数矩阵：

𝐇(𝐱)=(∂2f∂xi∂xj).

若 𝐇 在定义域上处处半正定，f 是凸函数；若正定，严格凸。二阶泰勒展开的二次项就是

12Δ𝐱⊤𝐇Δ𝐱,

所以正定性决定了局部极小、极大还是鞍点。

协方差矩阵

Σ=𝔼[(𝐗−μ)(𝐗−μ)⊤]

一定是对称半正定的。对任意方向 𝐮，方差

Var(𝐮⊤𝐗)=𝐮⊤Σ𝐮≥0.

它的特征值就是各主方向的方差，特征向量就是主成分方向。

注意：正定要求对所有非零向量都严格大于 0。只检查几个方向不够，必须用特征值或顺序主子式。

7. 工程视角：优化与不确定性

  • 优化：梯度下降的收敛速度由 Hessian 的条件数决定；正定性保证牛顿方向是下降方向。
  • 控制：Lyapunov 函数常取二次型 V(𝐱)=𝐱⊤𝐏𝐱，𝐏 正定表示能量为正。
  • 估计：卡尔曼滤波用协方差矩阵描述状态不确定性，置信椭球的形状由特征值决定。
  • 机器学习：损失函数的 Hessian 正定意味着局部极小；高斯过程的核矩阵必须半正定。
  • 结构力学：刚度矩阵正定意味着结构稳定，否则存在零能量变形模式。

小实验：用 NumPy 检查正定性并画特征方向。

import numpy as np

A = np.array([[2, 1], [1, 2]], dtype=float)
vals, vecs = np.linalg.eigh(A)  # 对称矩阵专用，返回升序特征值
print(vals)                     # [1., 3.]
print(np.all(vals > 0))         # True

点击展开（做完再看） **1.** 交叉项系数 4 平分给两个非对角元：
𝐀=(3221).
**2.** 特征值为 3,1，都大于 0，所以正定。 **3.** 特征多项式为 (1−λ)2−4=(λ−3)(λ+1)，特征值为 3,−1，不定。 **4.** 半轴长度为 1/λi，即 1 和 12。 **5.** 对任意向量 𝐮，
