1. 矩阵求导的记号

本课采用分母布局：标量 f 对向量 𝐱∈ℝn 的导数，是一个与 𝐱 同形状的列向量：

∂f∂𝐱=(∂f∂x1⋮∂f∂xn).

标量 f 对矩阵 𝐗 的导数，是与 𝐗 同形状的矩阵，逐元素求偏导。

标量对向量求导得到向量，向量对向量求导得到矩阵（Jacobian），标量对向量求两次导得到 Hessian。记号统一后，很多公式可以像普通微积分一样操作。

提醒：不同教材可能采用分子布局，结果会转置。看论文或代码时，先确认布局约定，再对公式。

2. 三个常用公式

线性型：

∂(𝐚⊤𝐱)∂𝐱=𝐚.

因为 𝐚⊤𝐱=∑iaixi，对 xi 求偏导得 ai，拼成向量就是 𝐚。

二次型：

∂(𝐱⊤𝐀𝐱)∂𝐱=(𝐀+𝐀⊤)𝐱.

若 𝐀 对称，则等于 2𝐀𝐱。

最小二乘目标：

∂‖𝐀𝐱−𝐛‖2∂𝐱=2𝐀⊤(𝐀𝐱−𝐛).

推导：把范数平方展开：

‖𝐀𝐱−𝐛‖2&=(𝐀𝐱−𝐛)⊤(𝐀𝐱−𝐛)&=𝐱⊤𝐀⊤𝐀𝐱−2𝐛⊤𝐀𝐱+𝐛⊤𝐛.

前两项分别用二次型和线性型公式，得

2𝐀⊤𝐀𝐱−2𝐀⊤𝐛=2𝐀⊤(𝐀𝐱−𝐛).

令导数为零，就得到正规方程

𝐀⊤𝐀𝐱=𝐀⊤𝐛.

这正是第 05 课用几何方法得到的结论。矩阵微积分给出了纯代数的推导。

3. 链式法则、Jacobian 与 Hessian

设 𝐠:ℝn→ℝm，f:ℝm→ℝ，则

∂f(𝐠(𝐱))∂𝐱=𝐉g(𝐱)⊤∇f(𝐠(𝐱)),

其中 𝐉g 是 𝐠 的 Jacobian 矩阵：

(𝐉g)ij=∂gi∂xj.

这与一元链式法则 f′(g(x))g′(x) 是同一个结构，只是乘法变成了矩阵乘法。

Hessian 是二阶导矩阵：

𝐇f(𝐱)=(∂2f∂xi∂xj).

对二次型 f(𝐱)=𝐱⊤𝐀𝐱，Hessian 是 𝐀+𝐀⊤；若 𝐀 对称，就是 2𝐀。Hessian 的正定性决定驻点是极小、极大还是鞍点。

4. 范数与条件数

向量范数常用的有三种：

‖𝐱‖1=∑i|xi|,‖𝐱‖2=∑ixi2,‖𝐱‖∞=maxi|xi|.

矩阵范数衡量“最大放大倍数”。谱范数是最大奇异值：

‖𝐀‖2=σmax(𝐀).

Frobenius 范数把所有元素平方相加再开方：

‖𝐀‖F=∑i,jaij2.

对可逆方阵，条件数定义为

κ(𝐀)=‖𝐀‖‖𝐀−1‖=σmaxσmin.

它衡量相对误差的放大倍数：

‖δ𝐱‖‖𝐱‖≤κ(𝐀)‖δ𝐛‖‖𝐛‖.

条件数为 1 最好；条件数越大，矩阵越病态。双精度浮点大约有 16 位有效数字，若 κ≈1012，求逆后可能只剩 4 位可信数字。

5. 浮点误差与矩阵分解

计算机用有限位浮点数表示实数，舍入误差不可避免。数值线性代数的核心任务之一，是让算法在有限精度下仍然可靠。

常用分解：

分解 用途 复杂度
LU（带主元） 解方阵方程组 O(n3)
QR 最小二乘、特征值 O(mn2)
Cholesky 正定方程组 O(n3/3)
SVD 伪逆、降维、病态问题 O(mn2)

LU 分解把 𝐀 写成下三角和上三角的乘积，然后前代、回代各一次。必须选主元：若主元为 0 或很小，直接除会放大误差。列主元消元每次选当前列绝对值最大的元素作为主元。

迭代法适合大型稀疏矩阵，例如 Jacobi、Gauss–Seidel、共轭梯度。它们不直接分解矩阵，而是逐步逼近解，每步只需要矩阵乘向量，内存和计算量都可能远小于直接法。

6. 梯度下降与 Kalman 滤波

梯度下降就是沿着负梯度方向走：

𝐱k+1=𝐱k−α∇f(𝐱k).

对最小二乘目标，梯度是 2𝐀⊤(𝐀𝐱−𝐛)，所以更新为

𝐱k+1=𝐱k−2α𝐀⊤(𝐀𝐱k−𝐛).

步长 α 太大可能发散，太小收敛慢；最优步长与 𝐀⊤𝐀 的特征值有关。条件数越大，梯度下降越难收敛，这也是需要预条件或牛顿法的原因。

Kalman 滤波的更新公式大量使用矩阵运算：协方差矩阵的传播、卡尔曼增益 𝐊=𝐏𝐇⊤(𝐇𝐏𝐇⊤+𝐑)−1、状态更新，都是矩阵乘法、求逆和正定矩阵操作。数值实现中常用 Cholesky 分解和 Joseph 形式来保持协方差矩阵对称正定。

7. 工程视角：实时计算与数值稳定

  • 实时控制：无人机姿态控制每毫秒都要解小规模线性系统，选对分解比单纯追求理论最优更重要；
  • SLAM：大规模稀疏矩阵用因子图、稀疏 Cholesky、增量式求解；
  • 深度学习：反向传播就是链式法则的矩阵形式，框架自动计算 Jacobian 与梯度；
  • 数值稳定：优先用 QR/SVD，少用显式求逆；解 𝐀𝐱=𝐛 时用分解，不要先算 𝐀−1；
  • 单位与尺度：把变量缩放到相近量级，可以显著降低条件数。

小实验：比较“显式求逆再相乘”和“直接解方程”的数值差异。

import numpy as np

A = np.array([[1, 1], [1, 1 + 1e-8]])
b = np.array([2, 2 + 1e-8])
x1 = np.linalg.inv(A) @ b
x2 = np.linalg.solve(A, b)
print(x1)
print(x2)
print(np.linalg.cond(A))

8. 练习

  1. 设 f(𝐱)=𝐚⊤𝐱，𝐚=(1,2,3)⊤，求 ∇f。

  2. 设 f(𝐱)=𝐱⊤𝐀𝐱，𝐀=(1234)，求 ∇f。

  3. 推导 ‖𝐀𝐱−𝐛‖2 的梯度。

  4. 求 𝐀=diag(100,1) 的条件数。它病态吗？

  5. 解释为什么解线性方程组时通常不先求逆矩阵。

9. 答案与简解

点击展开（做完再看） **1.** ∇f=𝐚=(1,2,3)⊤。 **2.** 𝐀+𝐀⊤=(2558)，所以
∇f=(2558)𝐱.
**3.** 展开：
‖𝐀𝐱−𝐛‖2=𝐱⊤𝐀⊤𝐀𝐱−2𝐛⊤𝐀𝐱+𝐛⊤𝐛.
对 𝐱 求导，第一项给 2𝐀⊤𝐀𝐱，第二项给 −2𝐀⊤𝐛，所以
∇f=2𝐀⊤(𝐀𝐱−𝐛).
**4.** 条件数为 100/1=100。它有一定程度的病态，但不算特别严重；双精度下仍有约 14 位有效数字。 **5.** 显式求逆需要 O(n3) 次运算，而且会引入额外舍入误差；直接分解求解通常更快、更稳定。求逆只在需要逆矩阵本身（例如协方差传播）时才做。
