1. 联合分布

两个随机变量 X,Y 的联合分布描述它们一起取值的方式。

离散型用联合 PMF：

pX,Y(x,y)=P(X=x,Y=y).

连续型用联合 PDF fX,Y(x,y)，满足

fX,Y(x,y)≥0,∫−∞∞∫−∞∞fX,Y(x,y)dxdy=1.

区域 D 上的概率为

P((X,Y)∈D)=∬DfX,Y(x,y)dxdy.

联合分布包含两个变量之间的全部依赖信息，比单独看每个变量更完整。

2. 边缘分布与条件分布

从联合分布中“抹掉”一个变量，得到边缘分布：

pX(x)=∑ypX,Y(x,y),
fX(x)=∫−∞∞fX,Y(x,y)dy.

条件分布描述已知一个变量后，另一个变量的分布：

fY∣X(y∣x)=fX,Y(x,y)fX(x),fX(x)>0.

离散型同理，把 PDF 换成 PMF。

联合、边缘、条件三者的关系是概率论的核心：

fX,Y=fY∣XfX=fX∣YfY.

3. 独立性

若对任意 x,y 都有

fX,Y(x,y)=fX(x)fY(y),

称 X,Y 相互独立。离散型把 PDF 换成 PMF。

独立性的直观含义：知道一个变量的取值，不会改变另一个变量的分布。

独立性的推论：

  • 𝔼[XY]=𝔼[X]𝔼[Y]；
  • Cov(X,Y)=0；
  • 联合 CDF 等于边缘 CDF 的乘积；
  • 独立随机变量的函数仍然独立。

反之，协方差为 0 不能推出独立，除非是联合正态分布。对于联合正态，不相关与独立等价，这是正态分布的特殊性质。

4. 和的分布与卷积

设 Z=X+Y。若 X,Y 独立，连续型的 PDF 为卷积：

fZ(z)=∫−∞∞fX(x)fY(z−x)dx.

离散型为

pZ(k)=∑ipX(i)pY(k−i).

例 4.1　设 X,Y 独立且都服从 U(0,1)，求 Z=X+Y 的分布。

联合密度在单位正方形上为 1，所以 fZ(z) 等于直线 x+y=z 穿过正方形的长度：

  • 0<z<1 时，长度为 z；
  • 1≤z<2 时，长度为 2−z；
  • 其他情况为 0。

这是三角形分布。两个均匀分布相加，结果不再是均匀分布，而是中间高、两边低。

5. 协方差矩阵与多元正态

随机向量 𝐗=(X1,…,Xn)⊤ 的协方差矩阵为

Σ=Cov(𝐗)=𝔼[(𝐗−μ)(𝐗−μ)⊤],

其中 μ=𝔼[𝐗]。对角线是各分量的方差，非对角线是协方差。Σ 对称半正定。

线性变换：若 𝐘=𝐀𝐗+𝐛，则

𝔼[𝐘]=𝐀μ+𝐛,Cov(𝐘)=𝐀Σ𝐀⊤.

这条公式在误差传播、坐标变换、Kalman 滤波中反复出现。

多元正态记作 𝐗~𝒩(μ,Σ)，密度为

f(𝐱)=1(2π)n/2|Σ|1/2exp(−12(𝐱−μ)⊤Σ−1(𝐱−μ)).

它的等密度面是椭球，形状由 Σ 的特征值决定。

对二元正态，若相关系数为 ρ，则条件分布为

𝔼[Y∣X=x]=μY+ρσYσX(x−μX),
Var(Y∣X=x)=σY2(1−ρ2).

条件均值是 x 的线性函数，条件方差与 x 无关。这是 Kalman 滤波能用线性公式的原因。

6. 条件期望与全期望公式

条件期望 𝔼[Y∣X] 是随机变量 X 的函数，本身也是随机变量。它表示“已知 X 后，对 Y 的最佳平方预测”。

全期望公式：

𝔼[Y]=𝔼[𝔼[Y∣X]].

全方差公式：

Var(Y)=𝔼[Var(Y∣X)]+Var(𝔼[Y∣X]).

总方差 = 组内方差 + 组间方差。这个分解在方差分析、混合模型和强化学习中都很常见。

7. 工程视角：传感器融合与 Kalman

  • 传感器融合：两个传感器对同一状态的观测可以写成联合分布，条件化后得到融合估计；
  • Kalman 滤波：预测步用线性变换传播均值和协方差，更新步用条件高斯公式融合观测；
  • SLAM：地图点和位姿的联合分布高度相关，协方差矩阵的非对角块描述这种相关性；
  • 误差传播：多个误差源独立时，总方差相加；不独立时必须保留协方差项；
  • 高斯过程：有限个点的联合分布是多元正态，条件化就是回归。

一句话：多维概率的核心不是公式多，而是“联合—边缘—条件”这三件事的来回转换。Kalman 滤波就是这套转换的工程实现。

8. 练习

  1. 设 X,Y 独立，X~U(0,1)，Y~U(0,1)。求 P(X+Y≤1)。

  2. 设 X,Y 的联合 PMF 为

X\Y 0 1
0 0.2 0.3
1 0.3 0.2

求边缘分布，并判断 X,Y 是否独立。

  1. 设 X,Y 独立，X~Pois(2)，Y~Pois(3)，求 X+Y 的分布。

  2. 设 (X,Y) 服从二元正态，ρ=0.5，σX=σY=1，μX=μY=0。求 𝔼[Y∣X=2] 和 Var(Y∣X=2)。

  3. 设 𝐘=𝐀𝐗，Cov(𝐗)=𝐈，𝐀=(1101)。求 Cov(𝐘)。

9. 答案与简解

点击展开（做完再看） **1.** 单位正方形中满足 x+y≤1 的三角形面积为 12，联合密度为 1，所以概率为 12。 **2.** 边缘分布：
P(X=0)=0.5,P(X=1)=0.5,P(Y=0)=0.5,P(Y=1)=0.5.
但 P(X=0,Y=0)=0.2≠0.5×0.5=0.25，所以不独立。 **3.** 泊松分布具有可加性：X+Y~Pois(5)。 **4.** 由条件正态公式：
𝔼[Y∣X=2]=0.5×2=1,
Var(Y∣X=2)=1×(1−0.52)=0.75.
**5.**
Cov(𝐘)=𝐀𝐈𝐀⊤=(1101)(1011)=(2111).
