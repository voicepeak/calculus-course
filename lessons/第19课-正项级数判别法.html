本课目标：掌握比较判别法、极限比较法、比值判别法、根值判别法与积分判别法，能判断常见正项级数的敛散性。

使用方法：先看通项的结构，再选判别法。不要一上来就套比值法，很多题用比较法更快。

1. 正项级数的基本性质

如果级数

∑n=1∞an

的每一项都满足 an≥0，就称为正项级数。

关键性质：正项级数的部分和

SN=a1+a2+⋯+aN

是单调不减的：

S1≤S2≤S3≤⋯

因此：正项级数只有两种命运：

  • 部分和有上界 ⇒ 收敛；
  • 部分和无上界 ⇒ 发散到 +∞。

这个性质是后面所有判别法的基础。

2. 比较判别法

比较判别法：设从某一项开始，

0≤an≤bn

则：

  • 如果 ∑bn 收敛，那么 ∑an 也收敛；
  • 如果 ∑an 发散，那么 ∑bn 也发散。

记忆方法：小的收敛，大的也收敛；大的发散，小的也发散。

例 1：判断

∑n=1∞1n2+1

因为

1n2+1<1n2

而 ∑1n2 收敛（下一节会说明），所以原级数收敛。

例 2：判断

∑n=1∞12n+1

因为

12n+1<12n

而几何级数 ∑n=1∞12n 收敛，所以原级数收敛。

例 3：判断

∑n=1∞1n+2

因为

1n+2>1n+3>⋯

更简单地，与调和级数比较：

1n+2>13n(n≥1)

而 ∑13n 发散（调和级数的常数倍），所以原级数发散。

3. p-级数

形如

∑n=1∞1np

的级数称为 p-级数。

结论：

∑n=1∞1np{收敛,p>1,发散,p≤1

常见特例：

  • p=1：调和级数 ∑1n，发散；
  • p=2： ∑1n2，收敛；
  • p=12： ∑1n，发散。

p-级数是比较法最重要的“标尺”。看到分母是 n 的幂，先想 p-级数。

4. 极限比较法

直接比较有时不方便，可以比较通项的“主部”。

极限比较法：设 an>0， bn>0，且

limn→∞anbn=c
  • 如果 0<c<+∞，则 ∑an 与 ∑bn 同敛散；
  • 如果 c=0，且 ∑bn 收敛，则 ∑an 收敛；
  • 如果 c=+∞，且 ∑bn 发散，则 ∑an 发散。

使用步骤：

  1. 找出 an 中增长最快的项；
  2. 构造参考级数 bn；
  3. 求 anbn 的极限；
  4. 根据极限值下结论。

例 1：

∑n=1∞2n+1n3+3n

当 n 很大时，分子约为 2n，分母约为 n3，所以通项约为

2nn3=2n2

取 bn=1n2：

limn→∞2n+1n3+3n1n2=limn→∞2n3+n2n3+3n=2

因为 ∑1n2 收敛，所以原级数收敛。

例 2：

∑n=1∞n+1n2+2

通项约为

nn2=1n

取 bn=1n：

limn→∞n+1n2+21n=limn→∞n2+nn2+2=1

因为调和级数发散，所以原级数发散。

例 3：

∑n=1∞(1−cos1n)

当 x→0 时，

1−cosx~x22

所以

1−cos1n~12n2

取 bn=1n2，极限为 12。因为 ∑1n2 收敛，所以原级数收敛。

5. 比值判别法

比值判别法：设 an>0，且

limn→∞an+1an=ρ

则：

  • ρ<1：级数收敛；
  • ρ>1 或 ρ=+∞：级数发散；
  • ρ=1：判别法失效，需要换方法。

适用场景：通项中含阶乘、指数、 n 次方，前后项容易相除。

例 1：

∑n=1∞n2n
an+1an=n+12n+1n2n=n+12n→12<1

所以级数收敛。

例 2：

∑n=1∞2nn!
an+1an=2n+1(n+1)!2nn!=2n+1→0<1

所以级数收敛。

例 3：

∑n=1∞n!10n
an+1an=(n+1)!10n+1·10nn!=n+110→+∞

所以级数发散。

例 4：

∑n=1∞1n
an+1an=nn+1→1

比值判别法失效。但这个级数实际是发散的，需要用 p-级数或积分判别法。

6. 根值判别法

根值判别法：设 an>0，且

limn→∞ann=ρ

则：

  • ρ<1：级数收敛；
  • ρ>1 或 ρ=+∞：级数发散；
  • ρ=1：判别法失效。

适用场景：通项整体是 n 次方，或者可以写成 (⋯)n。

例 1：

∑n=1∞(n2n+1)n
ann=n2n+1→12<1

所以级数收敛。

例 2：

∑n=1∞(nn+1)n2
ann=(nn+1)n=1(1+1n)n→1e<1

所以级数收敛。

7. 积分判别法

积分判别法：设 f(x) 在 [1,+∞) 上连续、正、单调递减，且

an=f(n)

则

∑n=1∞an与∫1+∞f(x)dx

同敛散。

几何意义：级数是离散的矩形面积，积分是连续曲线下的面积，两者只差有限项。

例 1：

∑n=2∞1nlnn

取

f(x)=1xlnx

在 [2,+∞) 上连续、正、递减。计算积分：

∫2+∞dxxlnx=∫2+∞d(lnx)lnx=ln(lnx)|2+∞=+∞

积分发散，所以原级数发散。

例 2：

∑n=2∞1n(lnn)2
∫2+∞dxx(lnx)2=−1lnx|2+∞=1ln2

积分收敛，所以原级数收敛。

对比：分母中 lnn 的幂次， 1 次时发散， 2 次时收敛。这个结论很像 p-级数，但标尺换成了 lnn。

8. 判别法怎么选

拿到一个正项级数，按下面的顺序检查：

第一步：通项检验

如果 an 不趋于 0，直接发散，结束。

第二步：看结构

通项特征 优先方法
分母是 n 的多项式 p-级数或比较法
分子分母都是多项式 极限比较法（比较最高次）
含阶乘、指数 比值判别法
整体是 n 次方 根值判别法
含 lnn 积分判别法或比较法
几何级数 直接求和

第三步：多个方法都行时，选计算量最小的。

9. 易错点

  1. 比较法的方向不能反。要证明收敛，用“小于一个收敛级数”；要证明发散，用“大于一个发散级数”。
  2. 比值/根值判别法在 ρ=1 时失效，不能下结论，必须换方法。
  3. 极限比较法的极限必须是正有限数，才能断言同敛散； 0 和 +∞ 要按规则单独处理。
  4. p-级数的 p 是分母中 n 的指数，不要和分子次数混淆。
  5. 积分判别法要求单调递减，不能只看连续和正。
  6. 级数前面有限项不影响敛散性。例如从 n=2 开始、从 n=100 开始，结论一样。
  7. 不要把比值判别法用在通项不趋于 0 的级数上。先做通项检验，能省很多事。

10. 练习

  1. 判断 ∑n=1∞1n2+3 的敛散性。

  2. 判断 ∑n=1∞12n+1 的敛散性。

  3. 判断 ∑n=1∞3n+1n3+2 的敛散性。

  4. 判断 ∑n=1∞n23n 的敛散性。

  5. 判断 ∑n=1∞n!nn 的敛散性。

  6. 判断 ∑n=2∞1nlnn 的敛散性。

  7. 判断 ∑n=1∞(nn+1)n2 的敛散性。

  8. 判断 ∑n=1∞1n2+sin2n 的敛散性。

11. 答案与简解

点击展开（做完再看）

1. 收敛。

1n2+3<1n2

而 ∑1n2 收敛。

2. 发散。

12n+1>13n(n≥1)

而 ∑13n 发散。

3. 收敛。

通项约为 3nn3=3n2。取 bn=1n2：

limn→∞3n+1n3+21n2=limn→∞3n3+n2n3+2=3

所以与 ∑1n2 同敛散，收敛。

4. 收敛。用比值判别法：

an+1an=(n+1)23n+1·3nn2=(n+1)23n2→13<1

5. 收敛。用比值判别法：

an+1an=(n+1)!(n+1)n+1·nnn!=nn(n+1)n=(nn+1)n→1e<1

6. 发散。见本课积分判别法例 1。

7. 收敛。用根值判别法：

ann=(nn+1)n=1(1+1n)n→1e<1

8. 收敛。

因为

n2+sin2n≥n2

所以

1n2+sin2n≤1n2

而 ∑1n2 收敛。
