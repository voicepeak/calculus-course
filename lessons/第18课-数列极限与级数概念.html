1. 数列与数列极限

数列是按顺序排好的一列数：

a1, a2, a3, …, an, …

记作 {an}。例如：

an=1n:1, 12, 13, 14, …

数列极限描述的是：当 n 越来越大时，an 是否越来越接近某个固定的数。

定义（ε-N 语言）：如果存在常数 A，使得对任意 ε>0，都存在正整数 N，当 n>N 时，都有

|an−A|<ε

则称数列 {an} 收敛于 A，记作

limn→∞an=A

如果不存在这样的常数 A，就称数列发散。

直观理解：无论你要求多小的误差 ε，从某一项开始，后面的所有项都落在 (A−ε,A+ε) 内。

例：

limn→∞1n=0

因为对任意 ε>0，取 N>1ε，当 n>N 时，

|1n−0|=1n<1N<ε

2. 收敛数列的性质

设 {an} 收敛于 A，{bn} 收敛于 B。

性质一：极限唯一。一个收敛数列不可能有两个不同的极限。

性质二：收敛必有界。存在 M>0，使 |an|≤M 对一切 n 成立。

性质三：四则运算。

limn→∞(an±bn)=A±B
limn→∞(anbn)=AB
limn→∞anbn=AB(B≠0)

性质四：夹逼定理。如果从某一项开始，

an≤cn≤bn

且

limn→∞an=limn→∞bn=A

那么

limn→∞cn=A

例：求

limn→∞2n+1n+3

分子分母同除以 n：

2n+1n+3=2+1n1+3n→2+01+0=2

3. 几个重要极限

（1）

limn→∞1n=0

更一般地，对任意 p>0，

limn→∞1np=0

（2） 当 |q|<1 时，

limn→∞qn=0

例如：

(12)n→0

（3）

limn→∞(1+1n)n=e

这是自然常数 e 的定义之一，e≈2.71828。

（4）

limn→∞nn=1

这几个极限可以直接使用，不需要每次用定义证明。

4. 级数与部分和

把数列的各项加起来：

∑n=1∞an=a1+a2+a3+⋯

称为无穷级数，简称级数。

级数不能直接“加到底”，要借助部分和：

S1=a1
S2=a1+a2
S3=a1+a2+a3

一般地，

SN=∑n=1Nan

称为前 N 项部分和。

定义：如果部分和数列 {SN} 收敛于 S，则称级数收敛，并称 S 为级数的和：

∑n=1∞an=S

如果 {SN} 发散，则称级数发散。

核心思想：级数收敛 = 部分和数列收敛。所有级数问题，最终都转化为数列极限问题。

5. 几何级数

形如

∑n=0∞qn=1+q+q2+q3+⋯

的级数称为几何级数（等比级数），其中 q 是公比。

部分和公式：当 q≠1 时，

SN=1+q+q2+⋯+qN=1−qN+11−q

收敛性：

  • 当 |q|<1 时，qN+1→0，所以
S=11−q
  • 当 |q|≥1 时，qN+1 不趋于 0，级数发散。

结论：

∑n=0∞qn={11−q,|q|<1,发散,|q|≥1

例 1：

∑n=0∞(12)n=11−12=2

例 2：

∑n=0∞(23)n=11−23=3

例 3：

∑n=0∞2n=1+2+4+8+⋯

公比 q=2，|q|≥1，发散。

6. 级数收敛的必要条件

定理：如果级数

∑n=1∞an

收敛，那么

limn→∞an=0

证明：设部分和为 SN，级数和为 S。则

aN=SN−SN−1→S−S=0

注意：这是必要条件，不是充分条件。也就是说：

  • 级数收敛 ⇒ 通项趋于 0；
  • 通项趋于 0 ⇏ 级数收敛。

逆否命题：如果通项 an 不趋于 0，那么级数一定发散。这个结论在判断发散时非常好用。

例 1：

∑n=1∞nn+1

通项

nn+1→1≠0

所以级数发散。

例 2：

∑n=1∞(−1)n

通项在 −1 和 1 之间振荡，不趋于 0，所以发散。

例 3：

∑n=1∞1n

通项 1n→0，但级数发散。这说明通项趋于 0 不能保证收敛。

7. 调和级数为什么发散

调和级数

∑n=1∞1n=1+12+13+⋯

虽然通项趋于 0，但部分和会无限增大。

分组证明：

S2m=1+12+(13+14)+(15+⋯+18)+⋯+(12m−1+1+⋯+12m)
S2m>1+12+(14+14)+(18+⋯+18)+⋯+(12m+⋯+12m)
S2m=1+12+12+12+⋯+12
S2m=1+m2

当 m→∞ 时，1+m2→∞，所以部分和无界，级数发散。

结论：调和级数是“通项趋于 0 但级数发散”的经典反例。

8. 裂项相消级数

有些级数的通项可以拆成两个相邻项的差，求和时中间项会抵消。

例：

∑n=1∞1n(n+1)

先裂项：

1n(n+1)=1n−1n+1

于是

SN=(1−12)+(12−13)+⋯+(1N−1N+1)
SN=1−1N+1

当 N→∞ 时，

SN→1

所以

∑n=1∞1n(n+1)=1

方法总结：看到分母是相邻两个因式的乘积，先尝试裂项：

1n(n+k)=1k(1n−1n+k)

9. 易错点

  1. 级数收敛看部分和，不是看通项。通项趋于 0 只是必要条件。
  2. 几何级数要从 n=0 还是 n=1 开始，首项不同，和也不同。
  3. |q|=1 时几何级数发散：q=1 时和为 1+1+⋯，q=−1 时部分和在 1,0,1,0,… 之间振荡。
  4. 裂项时注意系数。1n(n+2) 裂项后要乘 12。
  5. 数列发散不一定趋于无穷。例如 (−1)n 发散，但既不趋于 +∞，也不趋于 −∞。
  6. 不要滥用极限四则运算。前提是参与运算的数列极限都存在。

11. 答案与简解

点击展开（做完再看）

1. 3

分子分母同除以 n2：

3n2+2nn2−1=3+2n1−1n2→3

2. 收敛，极限为 0。

因为

|(−1)nn|=1n→0

由夹逼定理，原数列趋于 0。

3. 收敛，和为 4。

公比 q=34，|q|<1，所以

∑n=0∞(34)n=11−34=4

4. 收敛，和为 1。见本课第 8 节。

5. 发散。通项 (−1)n 不趋于 0。

6. 收敛，和为 1。

∑n=1∞34n=3∑n=1∞(14)n=3·141−14=3·13=1

7. 分组：

S2m=1+12+(13+14)+⋯+(12m−1+1+⋯+12m)
S2m>1+12+(14+14)+⋯+(12m+⋯+12m)

第 k 组（从 2k−1+1 到 2k）的和至少是

12k·2k−1=122k

把这些下界相加，得到

12∑k=2N2k→+∞

所以部分和无界，级数发散。

8. 发散。

(nn+1)n=1(1+1n)n→1e≠0

通项不趋于 0，所以级数发散。
