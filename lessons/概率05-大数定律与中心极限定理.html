1. 收敛的几种含义

随机变量序列 Xn 收敛到 X，有几种不同的含义：

依概率收敛：对任意 ε>0，

P(|Xn−X|>ε)→0.

几乎必然收敛：P(limn→∞Xn=X)=1。例外情况只发生在概率为 0 的集合上。

依分布收敛：Xn 的 CDF 逐点收敛到 X 的 CDF。

三者强度不同：几乎必然收敛最强，依概率收敛次之，依分布收敛最弱。大数定律用前两种，中心极限定理用依分布收敛。

2. 大数定律

设 X1,X2,… 独立同分布，𝔼[Xi]=μ，方差有限。样本均值

X¯n=1n∑i=1nXi.

弱大数定律：

X¯n→Pμ,

即对任意 ε>0，P(|X¯n−μ|>ε)→0。

强大数定律：

X¯n→a.s.μ.

直观含义：样本足够多时，平均值会稳定在期望附近。这是“频率近似概率”的理论基础，也是 Monte Carlo 方法能工作的原因。

注意：大数定律要求期望存在。柯西分布的期望不存在，样本均值不会稳定到任何常数。

3. 中心极限定理

设 X1,X2,… 独立同分布，𝔼[Xi]=μ，Var(Xi)=σ2<∞。则

X¯n−μσ/n→dN(0,1).

等价地，当 n 足够大时，

X¯n≈N(μ,σ2n),
∑i=1nXi≈N(nμ,nσ2).

中心极限定理不要求 Xi 服从正态分布，只要求独立同分布、方差有限。无论原始分布是均匀、二项、指数还是别的，只要样本量足够大，均值的分布都近似正态。

这解释了为什么正态分布在自然界和工程中如此常见：大量独立小误差叠加，结果近似正态。

4. 正态近似与连续性修正

二项分布 X~B(n,p) 在 n 大、p 不接近 0 或 1 时，可以用正态近似：

X≈N(np,np(1−p)).

计算 P(X≤k) 时，离散分布用连续性修正更准确：

P(X≤k)≈Φ(k+0.5−npnp(1−p)),
P(X≥k)≈1−Φ(k−0.5−npnp(1−p)).

例 5.1　抛 100 次公平硬币，求正面次数不超过 60 的概率。

n=100，p=0.5，np=50，np(1−p)=5。用连续性修正：

P(X≤60)≈Φ(60.5−505)=Φ(2.1)≈0.9821.

若不做修正，用 Φ(2)=0.9772，略偏低。

5. 蒙特卡洛方法

Monte Carlo 用随机采样估计期望或积分。若 X1,…,Xn 独立同分布，则

𝔼[g(X)]≈1n∑i=1ng(Xi).

由大数定律，估计会收敛；由中心极限定理，误差大约为

σgn,

其中 σg 是 g(X) 的标准差。要把误差减半，样本量要增加到 4 倍。

例 5.2　估计积分

I=∫01exdx.

令 U~U(0,1)，则 I=𝔼[eU]。抽 n 个均匀样本，计算 eUi 的平均值即可。真值为 e−1≈1.718。

蒙特卡洛的优点是适用于高维、复杂区域；缺点是需要大量样本才能达到高精度。

6. 工程视角：噪声平均与仿真

  • 传感器降噪：对同一量重复测量 n 次取平均，噪声标准差降为原来的 1/n；
  • 仿真：用 Monte Carlo 评估系统在随机扰动下的成功率、碰撞概率、寿命分布；
  • 参数不确定性传播：从参数分布中采样，跑大量仿真，得到输出的分布；
  • 强化学习：用采样估计策略梯度，本质上也是蒙特卡洛；
  • 置信区间：由 CLT 得到 X¯±zα/2σn，下一课会正式讲。

工程直觉：单个样本很吵，但平均后就安静了。平均的精度只按 1/n 提升，所以想提高 10 倍精度，需要 100 倍数据。

7. 练习

  1. 叙述中心极限定理，并说明它需要哪些条件。

  2. 设 X1,…,X100 独立同分布，𝔼[Xi]=0.3，Var(Xi)=0.21。用 CLT 近似 P(|X¯−0.3|≤0.09)。

  3. 掷一枚公平骰子 100 次，求样本均值的标准差。

  4. 抛 100 次公平硬币，用连续性修正近似 P(X≥40)。

  5. 用 Monte Carlo 估计 ∫01x2dx，写出估计式和误差量级。

8. 答案与简解

点击展开（做完再看） **1.** 设 Xi 独立同分布，期望 μ、方差 σ2<∞，则
X¯−μσ/n→dN(0,1).
需要独立、同分布、方差有限；样本量足够大时近似成立。 **2.** 标准差为
0.21100=0.45810=0.0458.
区间半宽 0.09 约为 1.965 个标准误，所以
P≈Φ(1.965)−Φ(−1.965)≈0.95.
**3.** 骰子均值 3.5，方差 3512≈2.917，标准差 ≈1.708。样本均值的标准误为
1.70810≈0.171.
**4.** np=50，np(1−p)=5。连续性修正：
P(X≥40)≈1−Φ(39.5−505)=1−Φ(−2.1)=Φ(2.1)≈0.9821.
**5.** 令 U~U(0,1)，则
I=𝔼[U2]≈1n∑i=1nUi2.
误差量级为 σU2n。真值为 1/3。
