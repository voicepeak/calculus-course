1. 三重积分是什么

三重积分是对三维区域 Ω 上的函数进行积分：

∭Ωf(x,y,z)dV

其中 dV 是体积元素。

物理意义：如果 f(x,y,z) 是密度，那么

∭Ωf(x,y,z)dV

就是区域 Ω 的总质量。

几何意义：当 f(x,y,z)=1 时，

∭Ω1dV=|Ω|

就是区域 Ω 的体积。

直观理解：把 Ω 切成很多小块，每块体积为 ΔV，用 f 在块内的值乘以 ΔV，再全部加起来，取极限就是三重积分。

2. 直角坐标下的累次积分

长方体区域

如果

Ω=[a,b]×[c,d]×[e,f]

那么

∭Ωf(x,y,z)dV=∫ab∫cd∫eff(x,y,z)dzdydx

积分顺序可以交换（在函数连续时）。

例 1：

∭ΩxyzdV

其中 Ω=[0,1]×[0,2]×[0,3]。

因为被积函数可以分离变量，

∭ΩxyzdV=(∫01xdx)(∫02ydy)(∫03zdz)

计算：

∫01xdx=12
∫02ydy=2
∫03zdz=92

所以

∭ΩxyzdV=12·2·92=92

一般区域

如果区域由上下曲面围成：

Ω={(x,y,z)∣(x,y)∈D, z1(x,y)≤z≤z2(x,y)}

那么

∭ΩfdV=∬D(∫z1(x,y)z2(x,y)f(x,y,z)dz)dA

例 2：求由平面

x+y+z=1

和三个坐标面围成的四面体的体积。

区域为

Ω={(x,y,z)∣x≥0, y≥0, z≥0, x+y+z≤1}

体积：

V=∫01∫01−x∫01−x−ydzdydx

先算最内层：

∫01−x−ydz=1−x−y

再算中间层：

∫01−x(1−x−y)dy=[(1−x)y−y22]01−x=(1−x)22

最后：

V=∫01(1−x)22dx=12·13=16

3. 柱坐标

柱坐标与极坐标类似：

x=rcosθ,y=rsinθ,z=z

其中

r≥0,0≤θ<2π,z∈ℝ

体积元素：

dV=rdzdrdθ

注意：多出来的 r 是雅可比因子，不能漏。

例 1：计算

∭ΩzdV

其中

Ω={(x,y,z)∣x2+y2≤1, 0≤z≤2}

用柱坐标：

x2+y2≤1⇒0≤r≤1

所以

∭ΩzdV=∫02π∫01∫02z·rdzdrdθ

分离变量：

=(∫02πdθ)(∫01rdr)(∫02zdz)=2π·12·2=2π

例 2：求抛物面

z=x2+y2

与平面 z=1 围成的体积。

区域：

x2+y2≤1,x2+y2≤z≤1

即

r2≤z≤1

体积：

V=∫02π∫01∫r21rdzdrdθ

先算 z：

∫r21rdz=r(1−r2)

再算 r：

∫01r(1−r2)dr=12−14=14

最后：

V=2π·14=π2

4. 球坐标

球坐标：

x=ρsinφcosθ
y=ρsinφsinθ
z=ρcosφ

其中

ρ≥0,0≤φ≤π,0≤θ<2π

角的含义：

  • ρ：到原点的距离；
  • φ：与 z 轴正方向的夹角（极角）；
  • θ：在 xy 平面上的投影与 x 轴正方向的夹角（方位角）。

体积元素：

dV=ρ2sinφdρdφdθ

注意：球坐标的雅可比因子是 ρ2sinφ，不是 r。

例 1：求单位球的体积。

单位球：

ρ≤1,0≤φ≤π,0≤θ<2π

体积：

V=∫02π∫0π∫01ρ2sinφdρdφdθ

分离变量：

=(∫02πdθ)(∫0πsinφdφ)(∫01ρ2dρ)

计算：

∫02πdθ=2π
∫0πsinφdφ=[−cosφ]0π=2
∫01ρ2dρ=13

所以

V=2π·2·13=4π3

例 2：计算

∭Ω(x2+y2+z2)dV

其中 Ω 是单位球。

因为

x2+y2+z2=ρ2

所以

∭Ωρ2dV=∫02π∫0π∫01ρ2·ρ2sinφdρdφdθ

分离变量：

=2π·2·15=4π5

5. 对称性

关于坐标面对称：

  • 如果区域关于 xy 平面对称，且 f(x,y,−z)=−f(x,y,z)，则
∭ΩfdV=0
  • 如果 f(x,y,−z)=f(x,y,z)，则
∭ΩfdV=2∭Ω+fdV

其中 Ω+ 是 z≥0 的部分。

例：区域 Ω 是单位球，计算

∭ΩzdV

因为区域关于 xy 平面对称，且 z 是 z 的奇函数，所以

∭ΩzdV=0

常见奇函数： x、 y、 z、 xyz 等。遇到对称区域，先看奇偶性，可以省很多计算。

6. 易错点

  1. 柱坐标的体积元素是 rdzdrdθ，不要漏掉 r。
  2. 球坐标的体积元素是 ρ2sinφdρdφdθ，不要漏掉 ρ2sinφ。
  3. 球坐标中 φ 的范围是 [0,π]，不是 [0,2π]。
  4. 积分限要由区域决定，不能机械地都写 0 到 1。
  5. 先画区域再写限。三重积分最容易错在上下限。
  6. 对称性使用前要确认区域和被积函数都满足条件。
  7. 交换积分顺序时，限也要跟着变，不能只换符号。

7. 练习

  1. 计算 ∭Ω(x2+y2)dV，其中 Ω=[0,1]×[0,1]×[0,1]。

  2. 求由 x+y+z=1 和三个坐标面围成的四面体体积。

  3. 计算 ∭ΩzdV，其中 x2+y2≤4， 0≤z≤3。

  4. 求抛物面 z=x2+y2 与平面 z=4 围成的体积。

  5. 用球坐标求单位球的体积。

  6. 计算 ∭Ω(x2+y2+z2)dV，其中 Ω 是单位球。

  7. 计算 ∭ΩxdV，其中 Ω 是单位球。
