1. 向量是什么

同一个对象，有三种同样重要的看法。

几何视角：向量是有方向、有长度的箭头。二维平面里的 𝐚=(3,2) 表示从原点出发，向右 3、向上 2。

代数视角：向量是一列数：

𝐚=(32),𝐛=(−140)

分量的个数叫维数。𝐚 是二维向量，𝐛 是三维向量。

数据视角：向量是一个样本或一个状态。例如无人机的状态可以写成

𝐱=(xyzvxvyvz),

前三个分量是位置，后三个是速度。传感器的一次读数、图像的一块特征、神经网络一层的激活值，也都可以看成一个向量。

这三种视角说的是同一件事。几何帮助建立直觉，代数方便计算，数据视角连接工程。

2. 加法与数乘

加法逐分量进行：

𝐚+𝐛=(a1⋮an)+(b1⋮bn)=(a1+b1⋮an+bn)

几何上，把 𝐛 的起点平移到 𝐚 的终点，从 𝐚 的起点指向 𝐛 的终点，就是 𝐚+𝐛（三角形法则）。也可以把两个向量首尾相接补成平行四边形，取对角线。

数乘把每个分量乘以同一个数：

c𝐚=(ca1⋮can)

c>0 时方向不变，长度变为 |c| 倍；c<0 时方向反过来；c=0 得到零向量 0。

加法满足交换律、结合律，数乘满足分配律。这些性质看起来显然，但后面所有线性运算都建立在它们之上。

注意：只有维数相同的向量才能相加。(1,2) 和 (1,2,3) 相加没有定义。

3. 线性组合与张成

给定向量 𝐯1,…,𝐯k 和数 c1,…,ck，称

c1𝐯1+c2𝐯2+⋯+ck𝐯k

为它们的一个线性组合。系数 ci 可以取任意实数，也可以全为 0。

所有可能的线性组合组成的集合，叫这组向量的张成空间（span），记作

span{𝐯1,…,𝐯k}={c1𝐯1+⋯+ck𝐯k∣ci∈ℝ}.

直观上，张成就是“用这些向量能到达的所有地方”。

  • 一个非零向量的张成是一条过原点的直线。
  • 两个不共线向量的张成是整个平面。
  • 三个不共面向量的张成是整个三维空间。
  • 如果其中一个向量能被其他向量组合出来，它就不会扩大张成。

例 1.1　判断 𝐛=(3,5,7) 是否在 𝐯1=(1,1,1)、𝐯2=(1,2,3) 的张成中。

设 𝐛=c1𝐯1+c2𝐯2，逐分量比较：

{c1+c2=3,c1+2c2=5,c1+3c2=7.

由前两式相减得 c2=2，再得 c1=1。代入第三式：1+3·2=7，成立。所以

𝐛=𝐯1+2𝐯2,

即 𝐛 在张成中。

如果第三个方程不成立，例如 𝐛=(3,5,8)，那么前两式仍给出 c1=1,c2=2，但第三式要求 1+6=8，矛盾，此时 𝐛 不在张成中。

4. 线性相关与线性无关

一组向量 𝐯1,…,𝐯k 称为线性相关，如果存在不全为零的数 c1,…,ck，使得

c1𝐯1+⋯+ck𝐯k=0.

如果只有全取零才成立，就称它们线性无关。

这句话的含义是：相关，说明至少有一个向量是“多余”的，它能被其他向量线性组合出来；无关，说明每个向量都提供了新的方向，谁也替代不了谁。

例 1.2　𝐯1=(1,2,3)，𝐯2=(2,4,6)。

显然 𝐯2=2𝐯1，所以

2𝐯1−𝐯2=0,

系数 (2,−1) 不全为零，故线性相关。

例 1.3　𝐯1=(1,0)，𝐯2=(0,1)。

设 c1𝐯1+c2𝐯2=0，即 (c1,c2)=(0,0)，所以 c1=c2=0。故线性无关。

几个常用结论：

  1. 含零向量的向量组一定线性相关。
  2. 两个向量线性相关，当且仅当其中一个是另一个的倍数（共线）。
  3. 在 ℝn 中，任意 n+1 个向量一定线性相关。例如平面上任意 3 个向量必相关，空间中任意 4 个向量必相关。
  4. 向量组线性无关，等价于其中任何一个向量都不能由其余向量线性表示。

易错点：判断相关性时，不能只看“看起来像不像”。必须解齐次方程，或者用秩、行列式等工具。第 03、04 课会给出系统方法。

5. 基与维数

如果一组向量既线性无关，又能张成整个空间，就称它为该空间的一组基。

基的两个条件缺一不可：

  • 无关，保证没有多余向量；
  • 张成，保证没有遗漏方向。

ℝn 的标准基是

𝐞1=(1,0,…,0),𝐞2=(0,1,…,0),…,𝐞n=(0,…,0,1).

任何向量 (x1,…,xn) 都可以唯一地写成

x1𝐞1+⋯+xn𝐞n.

一组基中向量的个数叫空间的维数。ℝ2 是二维，ℝ3 是三维，ℝn 是 n 维。

同一个空间可以有很多组基。例如

𝐮1=(1,1),𝐮2=(1,−1)

也是 ℝ2 的一组基：它们不共线，能张成平面。同一个向量在不同基下的坐标不同，但向量本身不变。坐标变换是后面矩阵部分的核心。

6. 工程视角：状态、特征与传感器

在无人机和具身智能里，向量几乎无处不在：

  • 状态向量：位置、速度、姿态、角速度拼成一个向量，滤波器在每一步更新它。
  • 观测向量：相机、IMU、激光雷达的一次测量是一个向量，噪声让它落在真值附近。
  • 特征向量：机器学习把一张图、一段语音变成高维向量，再在其中做分类或检索。
  • 控制输入：四个电机的推力可以看成一个向量，通过混控矩阵变成力和力矩。

线性组合则描述了“叠加”：

  • 两个传感器对同一位置的估计，可以按权重组合成一个更可靠的估计；
  • 神经网络的一层，本质上是把输入向量做若干次线性组合，再套一个非线性函数；
  • 无人机的位置，可以写成“起点 + 速度 × 时间”的线性组合。

线性代数的第一课不是要你会算多大的矩阵，而是让你习惯把工程问题写成向量和线性组合。后面所有内容——矩阵、秩、特征值、SVD——都在回答同一个问题：这些向量能张成什么？怎样用更少的基表示同样的信息？

小实验：用 NumPy 检查一组向量是否线性无关。若矩阵的秩等于向量个数，则它们线性无关：

import numpy as np

V = np.array([[1, 0, 2],
              [0, 1, 1],
              [1, 1, 3]])  # 每一列是一个向量
print(np.linalg.matrix_rank(V))  # 2，小于 3，说明三列线性相关

7. 练习

  1. 设 𝐚=(1,−2,3)，𝐛=(4,0,−1)，求 2𝐚−3𝐛。

  2. 判断 𝐯1=(1,2)，𝐯2=(2,4) 是否线性无关。

  3. 判断 𝐛=(1,2,3) 是否在 𝐯1=(1,1,0)、𝐯2=(0,1,1) 的张成中。

  4. 求 𝐯1=(1,1,0)、𝐯2=(0,1,1) 的张成空间，并写出它的方程。

  5. 设 𝐯1=(1,0,1)，𝐯2=(0,1,1)，𝐯3=(1,1,c)。问 c 取何值时，这三个向量线性相关？

8. 答案与简解

点击展开（做完再看） **1.** 2𝐚=(2,−4,6)，3𝐛=(12,0,−3)，所以
2𝐚−3𝐛=(−10,−4,9).
**2.** 因为 𝐯2=2𝐯1，所以线性相关。 **3.** 设 𝐛=c1𝐯1+c2𝐯2，得到
{c1=1,c1+c2=2,c2=3.
由第一式 c1=1，第三式 c2=3，但第二式要求 1+3=2，矛盾。所以 𝐛 不在张成中。 **4.** 张成中的向量形如
c1(1,1,0)+c2(0,1,1)=(c1,c1+c2,c2).
令 x=c1，y=c1+c2，z=c2，则 y=x+z，即
x−y+z=0.
这是一个过原点的平面。 **5.** 设 c1𝐯1+c2𝐯2+c3𝐯3=0，逐分量得到
{c1+c3=0,c2+c3=0,c1+c2+cc3=0.
由前两式 c1=c2=−c3，代入第三式：
−c3−c3+cc3=(c−2)c3=0.
若 c=2，取 c3=1 可得非零解，三向量线性相关；若 c≠2，则只能 c3=0，进而 c1=c2=0，三向量线性无关。
