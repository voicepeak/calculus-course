1. 随机变量

随机变量是把样本点映射成实数的函数：

X:Ω→ℝ.

例如掷两枚骰子，令 X 为点数之和，则 X 可以取 2,3,…,12。随机变量不是“随机的变量”，而是一个确定的函数；随机性来自样本点本身。

随机变量可以是：

  • 离散型：取值有限或可列，例如人数、次数、到达数；
  • 连续型：取值充满一个区间，例如时间、距离、电压；
  • 也有混合型，但入门阶段先掌握前两类。

2. 离散型与概率质量函数

离散型随机变量 X 的分布用概率质量函数（PMF）描述：

pX(x)=P(X=x).

它满足

pX(x)≥0,∑xpX(x)=1.

任意事件 A 的概率，就是把 A 中所有取值的概率相加：

P(X∈A)=∑x∈ApX(x).

3. 连续型、密度函数与分布函数

连续型随机变量用概率密度函数（PDF）fX(x) 描述，满足

fX(x)≥0,∫−∞∞fX(x)dx=1.

概率通过积分计算：

P(a≤X≤b)=∫abfX(x)dx.

分布函数（CDF）对离散和连续都适用：

FX(x)=P(X≤x).

连续型时

FX(x)=∫−∞xfX(t)dt,fX(x)=FX′(x).

重要：fX(x) 本身不是概率。连续型随机变量取某个具体值的概率为 0：

P(X=x)=0.

因此 P(a<X<b)=P(a≤X≤b)，端点不影响积分。

CDF 有三个性质：单调不减、右连续、limx→−∞F=0，limx→+∞F=1。

5. 常见连续分布

指数分布有“无记忆性”：

P(X>s+t∣X>s)=P(X>t).

已经等了 s 分钟，再等 t 分钟的概率与重新开始一样。泊松过程的到达间隔服从指数分布，这两个分布是一对搭档。

正态分布是最重要的连续分布。标准化：

Z=X−μσ~N(0,1).

常用区间概率：

P(|X−μ|≤σ)≈0.6827,
P(|X−μ|≤2σ)≈0.9545,
P(|X−μ|≤3σ)≈0.9973.

6. 随机变量变换

已知 X 的分布，求 Y=g(X) 的分布。

若 g 严格单调、可导，反函数为 h=g−1，则

fY(y)=fX(h(y))|h′(y)|.

例 2.2　设 X~U(0,1)，令 Y=−lnX，求 Y 的分布。

当 y>0 时，

FY(y)=P(−lnX≤y)=P(X≥e−y)=1−e−y.

求导得

fY(y)=e−y,y>0,

即 Y~Exp(1)。

这个变换叫逆变换采样：只要能从均匀分布采样，就能通过 −lnU 生成指数分布样本。更一般地，若 F 是目标分布的 CDF，则 F−1(U) 服从目标分布。这是蒙特卡洛仿真的基础。

7. 工程视角：噪声与到达过程

  • 传感器噪声：陀螺仪、加速度计的零偏和噪声常建模为正态分布；激光测距的误差也常用正态近似。
  • 到达过程：网络数据包、行人、车辆、光子到达常用泊松过程；到达间隔服从指数分布。
  • 可靠性：元件寿命常用指数分布或威布尔分布；指数分布的无记忆性让计算简化。
  • 仿真：逆变换采样把均匀随机数变成任意分布的样本，是 Monte Carlo 的第一步。
  • 异常检测：用分布的分位数设定阈值，例如超出 3σ 视为异常。

小实验：用 NumPy 生成正态与指数样本，检查均值和方差。

import numpy as np

x = np.random.normal(loc=0, scale=2, size=100000)
y = np.random.exponential(scale=1/3, size=100000)  # 速率 lambda=3
print(x.mean(), x.var())
print(y.mean(), y.var())
