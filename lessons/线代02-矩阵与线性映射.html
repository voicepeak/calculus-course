1. 矩阵是线性映射

一个 m×n 矩阵是 m 行、n 列的数表：

𝐀=(a11a12⋯a1na21a22⋯a2n⋮⋮⋱⋮am1am2⋯amn).

它把 n 维向量变成 m 维向量：

𝐀:ℝn→ℝm,𝐱↦𝐀𝐱.

这个映射有两个关键性质：

𝐀(𝐱+𝐲)=𝐀𝐱+𝐀𝐲,𝐀(c𝐱)=c𝐀𝐱.

也就是“先相加再变换”等于“先变换再相加”，“先缩放再变换”等于“先变换再缩放”。满足这两条的映射叫线性映射。

矩阵不是一堆孤立的数字，它是线性映射在标准基下的坐标表。换一组基，同一个映射会写成另一个矩阵，但它做的事情没有变。

2. 矩阵乘向量：列的线性组合

设 𝐀 的列向量为 𝐚1,…,𝐚n，则

𝐀𝐱=x1𝐚1+x2𝐚2+⋯+xn𝐚n.

这是理解矩阵乘法最重要的一个视角：𝐀𝐱 是 𝐀 的各列按 𝐱 的分量加权后的线性组合。

例如

(1234)(56)=5(13)+6(24)=(5+1215+24)=(1739).

按行计算也能得到同样结果：

(1·5+2·63·5+4·6)=(1739).

行视角适合手算，列视角适合理解。看到 𝐀𝐱 时，先想到“列的线性组合”，很多结论会变得自然。

推论：𝐀𝐱=0 有非零解，等价于 𝐀 的列向量线性相关。这正是第 01 课的相关性与第 03 课零空间的连接点。

3. 矩阵乘法：复合映射

若 𝐁 把 𝐱 变成 𝐁𝐱，再用 𝐀 变换，得到

𝐀(𝐁𝐱)=(𝐀𝐁)𝐱.

所以矩阵乘法定义成“先做右边的映射，再做左边的映射”。这就是为什么

(𝐀𝐁)𝐂=𝐀(𝐁𝐂)

（结合律成立），但一般

𝐀𝐁≠𝐁𝐀

（交换律不成立）。映射的复合本来就不交换：先旋转再平移，和先平移再旋转，结果不同。

例 2.1　取

𝐀=(1101),𝐁=(1011).

则

𝐀𝐁=(2111),𝐁𝐀=(1112).

两者不同，说明矩阵乘法一般不可交换。

从列视角看，𝐀𝐁 的第 j 列是 𝐀 乘以 𝐁 的第 j 列，也就是 𝐁 第 j 列在 𝐀 下的像。这个视角在推导分块矩阵乘法时特别有用。

4. 转置、单位阵与逆矩阵

转置把行和列互换：

(𝐀⊤)ij=aji.

例如

(123456)⊤=(142536).

常用性质：

(𝐀⊤)⊤=𝐀,(𝐀+𝐁)⊤=𝐀⊤+𝐁⊤,(𝐀𝐁)⊤=𝐁⊤𝐀⊤.

最后一条的顺序会反过来，和逆矩阵的规则一样。

单位阵 𝐈 是对角线为 1、其余为 0 的方阵，满足

𝐈𝐀=𝐀𝐈=𝐀.

逆矩阵 𝐀−1 满足

𝐀𝐀−1=𝐀−1𝐀=𝐈.

只有方阵才谈逆矩阵，而且不是每个方阵都有逆。对于 2×2 矩阵，

𝐀=(abcd),𝐀−1=1ad−bc(d−b−ca),

前提是 ad−bc≠0。这个数就是行列式，第 06 课会详细讲。

逆矩阵的意义是“撤销变换”。如果 𝐲=𝐀𝐱 且 𝐀 可逆，那么

𝐱=𝐀−1𝐲.

5. 几类常用矩阵

名称 形式或条件 作用
对角矩阵 非对角元全为 0 各分量独立缩放
上三角矩阵 对角线下方全为 0 消元后的形式
对称矩阵 𝐀⊤=𝐀 协方差、Hessian
正交矩阵 𝐐⊤𝐐=𝐈 旋转、反射，保持长度
旋转矩阵 (cosθ−sinθsinθcosθ) 平面旋转

正交矩阵满足 𝐐−1=𝐐⊤，计算逆矩阵几乎不花代价，而且数值稳定。这是它在工程中受欢迎的原因。

二维旋转矩阵作用在 (1,0) 上：

(cosθ−sinθsinθcosθ)(10)=(cosθsinθ),

正好是单位圆上角度为 θ 的点。作用在任意向量上，长度不变，只改变方向。

6. 工程视角：坐标变换与神经网络

坐标变换：无人机在不同坐标系之间转换位置，用的就是矩阵。世界坐标系到机体系的变换通常写成

𝐩body=𝐑world→body𝐩world.

如果涉及平移，还会把旋转矩阵扩成 4×4 的齐次变换矩阵。旋转矩阵是正交矩阵，它的逆就是转置。

神经网络：一层全连接层写成

𝐡=σ(𝐖𝐱+𝐛),

其中 𝐖 是权重矩阵，𝐛 是偏置向量，σ 是逐元素非线性函数。如果没有 σ，多层线性层叠起来仍然只是一个线性映射， depth 没有意义。

协方差矩阵：多个变量的方差和协方差排成一个对称矩阵。它描述不确定性的形状，第 08 课会用二次型解释它的几何意义。

小实验：验证矩阵乘法不可交换，并检查旋转矩阵是否正交。

import numpy as np

A = np.array([[1, 1], [0, 1]])
B = np.array([[1, 0], [1, 1]])
print(A @ B)
print(B @ A)

theta = np.pi / 2
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
print(np.allclose(R.T @ R, np.eye(2)))  # True
