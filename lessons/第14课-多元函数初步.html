1. 从一元到多元

一元函数是一个输入 x，一个输出 y。

二元函数是两个输入 x,y，一个输出 z：

z=f(x,y)

例如：

z=x2+y2

它的图像是一个曲面：高度由 x,y 共同决定。

2. 偏导数

对 x 求偏导，就是把 y 当成常数，只对 x 求导。

记作：

∂z∂x,fx,zx

对 y 求偏导，就是把 x 当成常数，只对 y 求导：

∂z∂y,fy,zy

符号 ∂ 读作“偏”，不是 d。

定义（看懂即可）

∂z∂x=limΔx→0f(x+Δx,y)−f(x,y)Δx

3. 偏导数例题

例 1

z=x2+3xy+y2

对 x 求偏导，把 y 当常数：

zx=2x+3y

对 y 求偏导，把 x 当常数：

zy=3x+2y

例 2

z=exy
zx=yexy
zy=xexy

例 3

z=ln(x2+y2)
zx=2xx2+y2
zy=2yx2+y2

例 4：在一点求值

z=x2y

先求偏导：

zx=2xy,zy=x2

在点 (1,2) 处：

zx(1,2)=2·1·2=4
zy(1,2)=12=1

4. 全微分

一元函数的微分：

dy=f′(x)dx

二元函数的全微分：

dz=zxdx+zydy

例 1

z=x2+3xy+y2
dz=(2x+3y)dx+(3x+2y)dy

例 2：近似计算

在点 (1,1) 附近，取：

dx=0.1,dy=0.2

先算该点的偏导：

zx=2+3=5
zy=3+2=5

所以：

dz=5·0.1+5·0.2=1.5

也就是说，z 大约增加 1.5。

5. 链式法则（简版）

设：

z=f(x,y),x=x(t),y=y(t)

则：

dzdt=∂z∂x·dxdt+∂z∂y·dydt

例

z=x2+y2,x=t,y=t2

先求偏导：

zx=2x,zy=2y

再乘上内层导数：

dzdt=2x·1+2y·2t

代入 x=t, y=t2：

dzdt=2t+4t2·t=2t+4t3

6. 易错点

  1. 对 x 求偏导时，y 要当常数，不要一起求导
  2. 对 y 求偏导时，x 要当常数
  3. ∂ 和 d 不是一回事
  4. 全微分有两项：zxdx+zydy
  5. 链式法则也有两项，别漏掉其中一项
  6. 在一点求偏导，先求偏导函数，再代点

7. 练习（8 题）

  1. z=x2+3xy+y2，求 zx,zy
  2. z=x3y2，求 zx,zy
  3. z=ex+2y，求 zx,zy
  4. z=ln(x2+y2)，求 zx,zy
  5. z=x2y，求在 (1,2) 处的 zx,zy
  6. z=x2+3xy+y2，求 dz
  7. z=x2+y2, x=t, y=t2，求 dzdt
  8. 用全微分近似 z=x2+3xy+y2 在 (1.1,0.9) 处的值
