1. 特征值与特征向量

矩阵 𝐀 作用在向量 𝐯 上，通常会改变它的方向和长度。但有些特殊方向，变换后方向不变，只是被拉伸或压缩。这些方向就是特征向量。

若存在非零向量 𝐯 和数 λ，使得

𝐀𝐯=λ𝐯,

则称 λ 是 𝐀 的特征值，𝐯 是对应的特征向量。

注意 𝐯≠0：零向量对任何 λ 都满足，没有信息量。λ 可以是 0、负数，也可以是复数。

几何上，𝐀 在特征向量方向上只做缩放，缩放比例就是 λ。若 |λ|>1，该方向被拉长；|λ|<1，被压缩；λ<0，方向反转。

2. 特征多项式

把定义改写：

𝐀𝐯=λ𝐯⟺(𝐀−λ𝐈)𝐯=0.

要使这个齐次方程有非零解，矩阵 𝐀−λ𝐈 必须奇异，即

det(𝐀−λ𝐈)=0.

左边是关于 λ 的 n 次多项式，叫特征多项式。它的根就是特征值。

例 7.1　求

𝐀=(2112)

的特征值与特征向量。

det(𝐀−λ𝐈)=|2−λ112−λ|=(2−λ)2−1=λ2−4λ+3=(λ−3)(λ−1).

特征值为 λ1=3，λ2=1。

对 λ1=3，解 (𝐀−3𝐈)𝐯=0：

(−111−1)(v1v2)=0⟹v1=v2.

取 𝐯1=(1,1)⊤。

对 λ2=1：

(1111)(v1v2)=0⟹v1=−v2.

取 𝐯2=(1,−1)⊤。

3. 特征空间与重数

固定特征值 λ，所有满足 𝐀𝐯=λ𝐯 的向量（包括零向量）组成特征空间：

Eλ=N(𝐀−λ𝐈).

它是零空间，所以一定是子空间。特征空间的维数叫几何重数，等于 n−rank(𝐀−λ𝐈)。

特征值在特征多项式中的重根数叫代数重数。恒有

1≤几何重数≤代数重数.

两者不一定相等。例如

𝐀=(1101)

的特征多项式是 (λ−1)2，代数重数为 2；但 𝐀−𝐈=(0100) 的秩为 1，几何重数为 2−1=1。这种矩阵不能对角化。

4. 对角化

若 𝐀 有 n 个线性无关的特征向量 𝐯1,…,𝐯n，把它们按列排成矩阵

𝐏=(𝐯1 ⋯ 𝐯n),

则

𝐀=𝐏𝐃𝐏−1,𝐃=diag(λ1,…,λn).

这叫对角化。𝐏 的列是特征向量，𝐃 的对角线是对应特征值。

对角化的条件：𝐀 有 n 个线性无关的特征向量。充分条件包括：

  • n 个特征值互不相同；
  • 𝐀 是对称矩阵（第 08 课会证明一定可以正交对角化）。

例 7.1 中

𝐏=(111−1),𝐃=(3001).

对角化的意义是换一组基。在这组特征向量基下，𝐀 的作用只是各方向独立缩放，矩阵变成对角阵，计算大大简化。

5. 矩阵幂与动力系统

由 𝐀=𝐏𝐃𝐏−1 得

𝐀k=𝐏𝐃k𝐏−1,𝐃k=diag(λ1k,…,λnk).

求高次幂时，不需要连乘 k 次，只要把特征值取 k 次方。

线性动力系统

𝐱k+1=𝐀𝐱k

的解为

𝐱k=𝐀k𝐱0=𝐏𝐃k𝐏−1𝐱0.

系统的长期行为由特征值决定：

  • 所有 |λi|<1：状态趋于 0，系统稳定；
  • 存在 |λi|>1：状态发散；
  • |λi|=1：可能振荡或保持有界。

这就是控制理论中“稳定性看特征值”的来源。

6. 复特征值与旋转

实矩阵也可能有复特征值，复特征值成对出现。例如旋转矩阵

𝐑=(0−110)

的特征多项式为 λ2+1=0，特征值为 ±i。它没有实特征向量，因为旋转 90∘ 会把任何实向量转离原来的方向。

复特征值的模长仍然描述伸缩：|λ|=1 对应纯旋转，|λ|>1 对应螺旋式发散。在离散动力系统中，复特征值对应振荡。

7. 工程视角：稳定性、模态与 PCA

特征值在工程里几乎无处不在：

  • 控制与动力学：无人机姿态的线性化模型，特征值决定模态是衰减、振荡还是发散；
  • 振动分析：结构的固有频率与振型就是特征值和特征向量；
  • 马尔可夫链：转移矩阵的特征值 1 对应平稳分布；
  • PCA：协方差矩阵的特征向量是主成分方向，特征值是对应方差；
  • PageRank：网页排序向量是转移矩阵特征值 1 的特征向量。

小实验：用 NumPy 求特征值，并验证 𝐀𝐯=λ𝐯。

import numpy as np

A = np.array([[2, 1], [1, 2]], dtype=float)
vals, vecs = np.linalg.eig(A)
print(vals)          # [3., 1.]
print(A @ vecs[:, 0] - vals[0] * vecs[:, 0])  # 接近零向量

8. 练习

  1. 求 (4123) 的特征值。

  2. 求 (1203) 的特征值。

  3. 设 3×3 矩阵的特征值为 2,5,−1，求它的行列式与迹。

  4. 证明旋转 90∘ 的矩阵没有实特征值。

  5. 若 𝐀 可逆，特征值为 λ1,…,λn，求 𝐀−1 的特征值。

9. 答案与简解

点击展开（做完再看） **1.**
det(𝐀−λ𝐈)=(4−λ)(3−λ)−2=λ2−7λ+10=(λ−5)(λ−2).
特征值为 5 和 2。 **2.** 上三角矩阵的特征值就是对角线元素：1 和 3。 **3.** 行列式等于特征值之积：
det𝐀=2·5·(−1)=−10.
迹等于特征值之和：
tr𝐀=2+5−1=6.
**4.** 旋转 90∘ 的矩阵为 (0−110)，特征多项式为 λ2+1=0，根为 ±i，不是实数。所以没有实特征值，也就没有实特征向量。 **5.** 若 𝐀𝐯=λ𝐯 且 λ≠0，两边左乘 𝐀−1 得
𝐯=λ𝐀−1𝐯⟹𝐀−1𝐯=1λ𝐯.
所以 𝐀−1 的特征值是 1/λ1,…,1/λn。
