1. 什么是微分方程

含有未知函数及其导数的方程，叫微分方程。

例子：

y′=2x
y′=y
y′+y=ex

解微分方程，就是找出满足方程的函数 y=y(x)。

最简单的例子

y′=2x

两边积分：

y=x2+C

验算： (x2+C)′=2x，正确。

2. 基本术语

术语 含义
阶 方程中出现的最高阶导数
通解 含任意常数 C 的解
特解 给 C 赋具体值后的解
初始条件 形如 y(0)=1 的条件，用来定 C

例：

y′=2x⇒y=x2+C(通解)

若再加 y(0)=1：

1=0+C⇒C=1
y=x2+1(特解)

3. 可分离变量法（核心）

标准形式：

dydx=f(x)g(y)

解法三步：

  1. 把含 y 的移到左边，含 x 的移到右边
  2. 两边分别积分
  3. 整理出 y
dyg(y)=f(x)dx
∫dyg(y)=∫f(x)dx

常数 C 只加一次，加在任意一边都行。

4. 基础例题

例 1

dydx=y

分离变量：

dyy=dx

两边积分：

ln|y|=x+C

去掉绝对值：

|y|=ex+C=eC·ex
y=Cex

（ C 可正可负， C=0 对应 y=0，也是解。）

例 2

dydx=2xy

分离：

dyy=2xdx

积分：

ln|y|=x2+C
y=Cex2

例 3

dydx=xy

分离：

ydy=xdx

积分：

y22=x22+C

整理：

y2=x2+C

例 4

dydx=yx

分离：

dyy=dxx

积分：

ln|y|=ln|x|+C
y=Cx

5. 带初始条件的题

例 1

dydx=2xy,y(0)=1

先求通解（上一节例 2）：

y=Cex2

代入 x=0, y=1：

1=Ce0=C

所以：

y=ex2

例 2

y′=y,y(0)=2

通解：

y=Cex

代入：

2=Ce0=C

特解：

y=2ex

顺序：先求通解，再代初始条件定 C，最后写特解。

6. 一阶线性方程（选学）

标准形式：

y′+P(x)y=Q(x)

通解公式：

y=e−∫P(x)dx[∫Q(x)e∫P(x)dxdx+C]

先记住公式，会用即可。

例

y′+y=ex

这里 P(x)=1, Q(x)=ex。

积分因子：

e∫1dx=ex
y=e−x[∫ex·exdx+C]=e−x[∫e2xdx+C]
=e−x[e2x2+C]
y=ex2+Ce−x

验算：

y′+y=(ex2−Ce−x)+(ex2+Ce−x)=ex

正确。

7. 应用背景

微分方程常用来描述"变化率"。

指数增长／衰减

dydx=ky

解：

y=Cekx
  • k>0：指数增长（人口、复利）
  • k<0：指数衰减（放射性物质、药物代谢）

这是微分方程最重要的应用模型之一。

8. 易错点

  1. 分离变量后，两边都要积分，不能只积一边
  2. 除以 g(y) 时，可能丢掉 g(y)=0 对应的解
  3. 常数 C 只加一次
  4. 先求通解，再代初始条件，顺序别反
  5. 解完代回原方程验算
  6. ln|y| 去绝对值时，用 C 吸收正负号
