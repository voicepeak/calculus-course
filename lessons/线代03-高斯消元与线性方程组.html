1. 线性方程组与增广矩阵

一个线性方程组写成

{a11x1+⋯+a1nxn=b1,⋮am1x1+⋯+amnxn=bm.

把系数和常数项排在一起，得到增广矩阵：

[𝐀∣𝐛]=(a11⋯a1nb1⋮⋱⋮⋮am1⋯amnbm).

解方程组时，我们只关心系数之间的关系，变量名 x1,…,xn 只是占位符。因此可以对增广矩阵做行变换，而不必反复抄写变量。

2. 初等行变换

下面三种操作不改变方程组的解集：

  1. 交换两行；
  2. 把某一行乘以一个非零常数；
  3. 把某一行的倍数加到另一行上。

这三种操作叫初等行变换。它们对应方程组的合法变形：交换方程顺序、两边同乘非零数、两个方程相减。

注意：不能交换列，因为列对应变量，交换列会改变变量的含义；不能把某行乘以 0，那会丢失方程。

高斯消元的目标，是用行变换把矩阵化成容易回代的形式。

3. 行阶梯形与简化行阶梯形

行阶梯形（row echelon form）满足：

  • 非零行在零行上方；
  • 每一行的第一个非零元（主元）在上一行主元的右边；
  • 主元所在列的下方全为 0。

简化行阶梯形（RREF）还要求：

  • 每个主元都是 1；
  • 主元所在列的其他元素全为 0。

例 3.1　解方程组

{x+y+z=6,2x−y+z=3,x+2y−z=2.

增广矩阵：

(11162−11312−12).

第二行减去第一行的 2 倍，第三行减去第一行：

(11160−3−1−901−2−4).

交换第二、三行，再把新的第二行乘以 −1：

(111601−2−40−3−1−9).

第三行加上第二行的 3 倍：

(111601−2−400−7−21).

第三行给出 −7z=−21，所以 z=3。回代：y−2·3=−4，得 y=2；x+2+3=6，得 x=1。解为

(x,y,z)=(1,2,3).

这一组主元在三个不同的列上，对应唯一解。

4. 秩与解的结构

矩阵 𝐀 的秩 rank(𝐀) 是行阶梯形中主元的个数，也就是非零行的个数。它衡量矩阵“真正独立的方向”有多少。

设方程组有 n 个未知数，𝐀 是 m×n 矩阵，r=rank(𝐀)。比较 rank(𝐀) 与 rank([𝐀∣𝐛])：

情况 解的结构
rank(𝐀)<rank([𝐀∣𝐛]) 无解
两者相等，且 r=n 唯一解
两者相等，且 r<n 无穷多解，有 n−r 个自由变量

直观解释：

  • 增广矩阵的秩更大，说明出现了 0=d 且 d≠0 的矛盾行，方程组不相容；
  • 每个未知数都对应一个主元，就没有自由变量，解唯一；
  • 有 n−r 列没有主元，这些列对应的变量可以自由取值，其他变量由它们决定。

例 3.2　

{x+2y+z=1,2x+4y+z=3,x+2y−z=3.

消元后得到

(121100−110000).

秩为 2，未知数 3 个，所以有无穷多解。由第二行 z=−1，代入第一行得 x=2−2y。令 y=t，则

(x,y,z)=(2−2t, t, −1),t∈ℝ.

几何上，这是三维空间中的一条直线。

5. 齐次方程组与零空间

常数项全为 0 的方程组 𝐀𝐱=0 叫齐次方程组。它永远有零解 𝐱=0，所以一定相容。

它的全部解组成矩阵 𝐀 的零空间（null space），记作 N(𝐀)：

N(𝐀)={𝐱∈ℝn∣𝐀𝐱=0}.

若 rank(𝐀)=r，则零空间的维数是 n−r。这个数叫零化度。

例 3.3　求

𝐀=(123246)

的零空间。

第二行是第一行的 2 倍，消元后只剩 x1+2x2+3x3=0。x2,x3 是自由变量，令 x2=s，x3=t，则 x1=−2s−3t。于是

𝐱=s(−210)+t(−301).

零空间是二维平面，基为 (−2,1,0)⊤ 和 (−3,0,1)⊤。

连接：非齐次方程 𝐀𝐱=𝐛 的通解，等于“一个特解 + 齐次方程的通解”。这与微积分里“非齐次线性微分方程的通解 = 特解 + 齐次通解”是同一个结构。

6. 工程视角：约束与平衡

线性方程组在工程里通常不是“作业题”，而是约束：

  • 无人机的力/力矩平衡：每个电机推力是未知数，机体受力平衡给出线性方程；
  • 电路网络：基尔霍夫定律给出节点电流和回路电压的线性方程；
  • 结构力学：桁架节点的受力平衡；
  • 机器学习：线性回归的正规方程 𝐀⊤𝐀𝐱=𝐀⊤𝐛；
  • 计算机视觉：多视图几何中的三角化与光束法平差。

工程中常见的三种情形正好对应上面的分类：

  • 唯一解：约束足够且独立，问题适定；
  • 无穷多解：约束不足，需要额外正则化或选一个最优解；
  • 无解：约束矛盾，通常说明模型有噪声，此时退而求最小二乘解（第 05 课）。

小实验：用 NumPy 判断方程组是否有解，并求一个特解。

import numpy as np

A = np.array([[1, 2, 1],
              [2, 4, 1],
              [1, 2, -1]])
b = np.array([1, 3, -1])
print(np.linalg.matrix_rank(A), np.linalg.matrix_rank(np.column_stack([A, b])))
print(np.linalg.lstsq(A, b, rcond=None)[0])  # 无穷多解时给出最小范数解

7. 练习

  1. 解方程组 {2x+y=5,x−y=1.

  2. 解方程组 {x+y+z=3,2x+2y+2z=6,x−y=0.

  3. 求 𝐀=(123246) 的秩和零空间维数。

  4. 讨论 k 取何值时，方程组 {x+y=2,2x+2y=k 有唯一解、无穷多解或无解。

  5. 判断方程组 {x+y=1,x+y=2 是否有解，并用秩解释。

8. 答案与简解

点击展开（做完再看） **1.** 第二式给出 x=y+1，代入第一式：2(y+1)+y=5，即 3y=3，y=1，x=2。解为 (2,1)。 **2.** 第二行是第一行的 2 倍，方程实际只有 x+y+z=3 和 x−y=0。由 x=y 得 2y+z=3，即 z=3−2y。令 y=t，解为
(x,y,z)=(t,t,3−2t).
**3.** 第二行是第一行的 2 倍，秩为 1，零空间维数为 3−1=2。零空间由 x1+2x2+3x3=0 给出，基为 (−2,1,0)⊤、(−3,0,1)⊤。 **4.** 第二式是 2(x+y)=k。若 k=4，与第一式相容，但两式成比例，秩为 1，未知数 2 个，有无穷多解；若 k≠4，则 x+y=2 与 x+y=k/2 矛盾，无解。不存在唯一解的情形，因为两行总是成比例。 **5.** 增广矩阵消元后出现 0=1，无解。rank(𝐀)=1，而 rank([𝐀∣𝐛])=2，增广矩阵的秩更大。
